## Три семьи задач ML

| Семья | Есть ответы Y? | Суть |
|:---|:---|:---|
| С учителем (supervised) | Да | Учимся по примерам (X, y) |
| Без учителя (unsupervised) | Нет | Ищем структуру (кластеры, PCA…) |
| С подкреплением (RL) | Награда за действие | Учимся методом проб и ошибок |

Дальше в `d.1` почти всё про **supervised**.

## Главная формула обучения

$$
\theta_{\text{best}} = \arg\min_{\theta} \frac{1}{n}\sum_{i=1}^{n} L\bigl(y_i,\ \hat y_\theta(x_i)\bigr)
$$

Средний штраф (эмпирический риск) → крутим параметры θ, пока он не станет минимальным.

## Типичный пайплайн

1. Разделить данные: Train / Validation (/ Test).
2. Обработать: пропуски, масштаб, кодирование категорий.
3. Выбрать модель + гиперпараметры → обучить на Train.
4. Смотреть качество на Validation; при необходимости повторить п.3.
5. Один раз проверить на Test.

## Что запомнить из введения

1. Тип задачи смотрим по **Y**: метка → классификация, число → регрессия, порядок → ранжирование.
2. **Loss** — штраф за один объект; **эмпирический риск** — средний Loss.
3. **Переобучение** ловим сравнением Train vs Validation/Test, а не «красивой» ошибкой на Train.
4. Введение — карта; рабочие детали живут в `d.2`/`d.3`.
