# d.1.2 Loss и эмпирический риск

> **Loss** — штраф за **один** объект.  
> **Эмпирический риск** — **средний** штраф по выборке.  
> **Обучение** — найти $\large{\theta}$, при котором средний штраф минимален.

Метрики качества (Accuracy, F1, ROC…) — отдельная тема: [`d.3.1`](../d.3%20Classic%20ML/d.3.1%20%D0%9C%D0%B5%D1%82%D1%80%D0%B8%D0%BA%D0%B8%20%D0%BA%D0%BB%D0%B0%D1%81%D1%81%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%86%D0%B8%D0%B8%20%D0%B8%20%D1%80%D0%B5%D0%B3%D1%80%D0%B5%D1%81%D1%81%D0%B8%D0%B8.md#precision--recall--f1--%D1%87%D0%B5%D1%80%D0%B5%D0%B7-%D0%BF%D0%BE%D1%80%D0%BE%D0%B3). Loss ≠ метрика отчёта, хотя иногда совпадают (MSE).

## 1. Три понятия

| Понятие | На скольких объектах | Роль |
|:---|:---|:---|
| Loss $\large{L(y,\hat y)}$ | Один | Штраф за ответ |
| Эмпирический риск $\large{R_{\mathrm{emp}}(\theta)}$ | Все $n$ | Средний штраф |
| Обучение | — | $\large{\theta_{\mathrm{best}} = \arg\min_\theta R_{\mathrm{emp}}(\theta)}$ |

$$
\Large R_{\mathrm{emp}}(\theta) = \frac{1}{n}\sum_{i=1}^{n} L\bigl(y_i,\ \hat y_\theta(x_i)\bigr)
$$

Запись «$\large{L(y,\hat y)}$ — любая функция (квадрат, модуль, log, hinge)» значит: **единой формулы Loss нет**, выбираем под задачу. Тире — «это», не минус.

## 2. Частые Loss

| Loss | Формула (на 1 объекте) | Когда |
|:---|:---|:---|
| Squared (MSE-слагаемое) | $\large{(y-\hat y)^2}$ | Регрессия; сильно бьёт по большим ошибкам |
| Absolute (MAE-слагаемое) | $\large{\lvert y-\hat y\rvert}$ | Регрессия с выбросами |
| Log loss | $\large{-y\log\hat y-(1-y)\log(1-\hat y)}$ | Бинарная классификация |
| Hinge | $\large{\max(0,\ 1-y\cdot\hat y)}$ | SVM |

## 3. Мини-пример на 5 квартирах

| № | $y$ | $\large{\hat y}$ | ошибка | squared | absolute |
|:---|:---|:---|:---|:---|:---|
| 1 | 5.0 | 4.2 | +0.8 | 0.64 | 0.8 |
| 2 | 7.5 | 8.1 | −0.6 | 0.36 | 0.6 |
| 3 | 6.0 | 6.5 | −0.5 | 0.25 | 0.5 |
| 4 | 10.0 | 9.0 | +1.0 | 1.00 | 1.0 |
| 5 | 3.5 | 4.0 | −0.5 | 0.25 | 0.5 |

$$
\Large
R_{\mathrm{MSE}} = \frac{2.50}{5} = 0.50,\qquad
R_{\mathrm{MAE}} = \frac{3.4}{5} = 0.68
$$

Модель меняет веса и снова считает $R$. Цель — уменьшить **средний** штраф, а не «подогнать один объект».

## 4. Параметры vs гиперпараметры

| | Параметры $\large{\theta}$ | Гиперпараметры |
|:---|:---|:---|
| Кто крутит | Оптимизатор / аналитика | Человек / поиск по сетке |
| Примеры | Веса линейной модели | $k$ в KNN, learning rate, степень полинома |
| Есть ли у KNN | Нет (ленивое запоминание) | Да — $k$, метрика |

## 5. Кто минимизирует риск

Кратко: градиентный спуск и его адаптивные варианты, иногда аналитическое решение (нормальное уравнение), иногда бустинг/деревья со своим правилом. ## Запомнить

1. Loss — один объект; риск — среднее.  
2. Универсальна формула **риска**; внутри неё — любой подходящий Loss.  
3. Обучение = $\large{\arg\min_\theta R_{\mathrm{emp}}}$.  
4. Гиперпараметры модель сама не «учит» — их подбирают снаружи (часто по Validation / CV).
