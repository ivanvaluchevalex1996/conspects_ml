# d.1.2 Loss и эмпирический риск

> **Loss** — штраф за **один** объект.  
> **Эмпирический риск** — **средний** штраф по выборке.  
> **Обучение** — найти \(\theta\), при котором средний штраф минимален.

Метрики качества (Accuracy, F1, ROC…) — отдельная тема: [`d.3.1`](../d.3%20Classic%20ML/d.3.1%20Метрики%20классификации%20и%20регрессии.md). Loss ≠ метрика отчёта, хотя иногда совпадают (MSE).

## 1. Три понятия

| Понятие | На скольких объектах | Роль |
|:---|:---|:---|
| Loss \(L(y,\hat y)\) | Один | Штраф за ответ |
| Эмпирический риск \(R_{\mathrm{emp}}(\theta)\) | Все \(n\) | Средний штраф |
| Обучение | — | \(\theta_{\mathrm{best}} = \arg\min_\theta R_{\mathrm{emp}}(\theta)\) |

$$
R_{\mathrm{emp}}(\theta) = \frac{1}{n}\sum_{i=1}^{n} L\bigl(y_i,\ \hat y_\theta(x_i)\bigr)
$$

Запись «\(L(y,\hat y)\) — любая функция (квадрат, модуль, log, hinge)» значит: **единой формулы Loss нет**, выбираем под задачу. Тире — «это», не минус.

## 2. Частые Loss

| Loss | Формула (на 1 объекте) | Когда |
|:---|:---|:---|
| Squared (MSE-слагаемое) | \((y-\hat y)^2\) | Регрессия; сильно бьёт по большим ошибкам |
| Absolute (MAE-слагаемое) | \(\lvert y-\hat y\rvert\) | Регрессия с выбросами |
| Log loss | \(-y\log\hat y-(1-y)\log(1-\hat y)\) | Бинарная классификация |
| Hinge | \(\max(0,\ 1-y\cdot\hat y)\) | SVM |

## 3. Мини-пример на 5 квартирах

| № | \(y\) | \(\hat y\) | ошибка | squared | absolute |
|:---|:---|:---|:---|:---|:---|
| 1 | 5.0 | 4.2 | +0.8 | 0.64 | 0.8 |
| 2 | 7.5 | 8.1 | −0.6 | 0.36 | 0.6 |
| 3 | 6.0 | 6.5 | −0.5 | 0.25 | 0.5 |
| 4 | 10.0 | 9.0 | +1.0 | 1.00 | 1.0 |
| 5 | 3.5 | 4.0 | −0.5 | 0.25 | 0.5 |

$$
R_{\mathrm{MSE}} = \frac{2.50}{5} = 0.50,\qquad
R_{\mathrm{MAE}} = \frac{3.4}{5} = 0.68
$$

Модель меняет веса и снова считает \(R\). Цель — уменьшить **средний** штраф, а не «подогнать один объект».

## 4. Параметры vs гиперпараметры

| | Параметры \(\theta\) | Гиперпараметры |
|:---|:---|:---|
| Кто крутит | Оптимизатор / аналитика | Человек / поиск по сетке |
| Примеры | Веса линейной модели | \(k\) в KNN, learning rate, степень полинома |
| Есть ли у KNN | Нет (ленивое запоминание) | Да — \(k\), метрика |

## 5. Кто минимизирует риск

Кратко: градиентный спуск и его адаптивные варианты, иногда аналитическое решение (нормальное уравнение), иногда бустинг/деревья со своим правилом. Подробно — [`d.0`](../d.0%20Градиент%20и%20правило%20цепочки.md), [`d.4.2`](../d.4%20Deep%20Learning/d.4.2%20Градиентная%20оптимизация.md), [`d.2.1.4`](../d.2%20Линейные%20модели%20метрические%20методы/d.2.1%20Линейные%20модели/d.2.1.4%20Градиент%20MSE%20и%20SGD%20для%20линейной%20регрессии.md).

## Запомнить

1. Loss — один объект; риск — среднее.  
2. Универсальна формула **риска**; внутри неё — любой подходящий Loss.  
3. Обучение = \(\arg\min_\theta R_{\mathrm{emp}}\).  
4. Гиперпараметры модель сама не «учит» — их подбирают снаружи (часто по Validation / CV).
