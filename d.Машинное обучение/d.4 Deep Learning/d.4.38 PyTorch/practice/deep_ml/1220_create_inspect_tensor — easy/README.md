## Что это за задача

Создать тензор, вывести **shape, dtype, device** — базовая «разведка».

## Зачем это в реальной жизни

90% багов в DL — «не тот shape/dtype/device». Перед обучением привычка смотреть `x.shape`, `x.dtype`, `x.device` экономит часы.
