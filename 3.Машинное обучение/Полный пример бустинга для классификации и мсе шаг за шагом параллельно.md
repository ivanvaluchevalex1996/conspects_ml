# **ШАГ 0.5. Softmax (только в классификации)**

## **MSE**

**Нет softmax.** Логиты — **уже** финальное предсказание. $a = 0$.

## **Классификация**

**Нужен softmax** — превратить логиты в **вероятности**.

**Для каждого объекта** применяем softmax к $[0,\ 0,\ 0]$:

$$
a_k = \frac{e^{0}}{e^{0} + e^{0} + e^{0}} = \frac{1}{3}
$$

| **Квартира** | $a_0$ | $a_1$ | $a_2$ |
|----|----|----|----|
| A | 0.333 | 0.333 | 0.333 |
| B | 0.333 | 0.333 | 0.333 |
| C | 0.333 | 0.333 | 0.333 |
| D | 0.333 | 0.333 | 0.333 |

**Смысл:** модель даёт **по** $1/3$ на каждый класс.

**Разница:**

- **MSE:** softmax **не нужен**.
- **Классификация:** softmax **обязателен** — переводит логиты в вероятности.

# **ШАГ 2. Строим деревья**

## **MSE**

**Одно дерево** $b_1$ на антиградиентах $[+4.0,\ +6.0,\ +8.0,\ +11.0]$.

**Цель:** предсказать эти числа.

**Ищем сплит:** «Площадь ≤ 60?»

- Слева (A, B): $+4.0$, $+6.0$. Среднее = **+5.0**.
- Справа (C, D): $+8.0$, $+11.0$. Среднее = **+9.5**.

**Дерево** $b_1$:

```text
        [Площадь ≤ 60?]
        /            \
      Да              Нет
      /                \
   +5.0              +9.5
```

## **Классификация**

### **Сводная таблица антиградиентов**

| **Объект** | $g_0$ | $g_1$ | $g_2$ |
|----|----|----|----|
| A | **+0.667** | −0.333 | −0.333 |
| B | −0.333 | **+0.667** | −0.333 |
| C | −0.333 | −0.333 | **+0.667** |
| D | −0.333 | **+0.667** | −0.333 |

$K$ **деревьев** — по одному на **каждый** класс.

**Почему нельзя одно дерево на всё**

**Дерево** — это функция b(x), которая выдаёт **одно число**.

**Если** бы мы хотели **одно** дерево, оно должно было бы выдавать **K чисел** — вектор. Но **решающее дерево** так **не умеет**. В листе — **одно** число (среднее).

**Обход:** **K деревьев**. Каждое — **своя** функция. Каждая — **своё** число.

**Каждое дерево** отвечает **только за одну метку**. Оно говорит: «насколько сдвинуть логит **этого** класса».

### **Дерево для класса 0 (то есть столбец** $g_0$**)**

**Цель:** $g_0 = [+0.667,\ -0.333,\ -0.333,\ -0.333]$.

**Пробуем «Площадь ≤ 40?»:**

- **Слева** (A): цель $+0.667$. **Одна** → дисперсия $0$.
- **Справа** (B, C, D): цели $-0.333$, $-0.333$, $-0.333$. **Однородны!** Дисперсия $0$.

**Общая impurity:** $0$. **Идеальный сплит!**

**Дерево** $b_0$:

```text
        [Площадь ≤ 40?]
        /            \
      Да              Нет
      /                \
   +0.667           −0.333
```

**Что записали в листья:**

- Слева: среднее = **+0.667**.
- Справа: среднее = **−0.333**.

### **Дерево для класса 1 (столбец** $g_1$**)**

| **Объект** | **Площадь** | **Цель** $g_1$ |
|----|----|----|
| A | 30 | −0.333 |
| B | 50 | **+0.667** |
| C | 70 | −0.333 |
| D | 90 | **+0.667** |

**Цель:** $g_1 = [-0.333,\ +0.667,\ -0.333,\ +0.667]$.

**Идеально** было бы: ${A, C}$ — минусы, ${B, D}$ — плюсы. Но B и D **не рядом** — C между ними. **Одним порогом** не справиться → берём **глубину 2**.

**Как дерево выбирает сплит.** Для каждого варианта считаем **взвешенную дисперсию** целей в листьях ($H$) и берём **минимальную**:

$$
H = \frac{n_L}{n}\,\mathrm{Var}(L) + \frac{n_R}{n}\,\mathrm{Var}(R)
$$

**Уровень 1 — корень.** Цели: $-0.333$, $+0.667$, $-0.333$, $+0.667$. Дисперсия в корне $= 0.25$.

| **Сплит** | **Слева** | **Справа** | $H$ |
|----|----|----|----|
| ≤ 40? | {A} | {B, C, D} | $\frac{1}{4}\cdot 0 + \frac{3}{4}\cdot 0.222 = $ **0.167** |
| ≤ 60? | {A, B} | {C, D} | $\frac{2}{4}\cdot 0.25 + \frac{2}{4}\cdot 0.25 = 0.25$ |
| ≤ 80? | {A, B, C} | {D} | $\frac{3}{4}\cdot 0.222 + \frac{1}{4}\cdot 0 = $ **0.167** |

Ничья между «≤ 40?» и «≤ 80?». Берём **«≤ 40?»**.

**Уровень 2 — делим правый лист {B, C, D}.** Цели: $+0.667$, $-0.333$, $+0.667$. Дисперсия $= 0.222$.

| **Сплит** | **Слева** | **Справа** | $H$ (внутри узла) |
|----|----|----|----|
| ≤ 60? | {B} | {C, D} | $\frac{1}{3}\cdot 0 + \frac{2}{3}\cdot 0.25 = 0.167$ |
| ≤ 80? | {B, C} | {D} | $\frac{2}{3}\cdot 0.25 + \frac{1}{3}\cdot 0 = 0.167$ |

Снова ничья. Берём **«≤ 60?»**: B получает свой лист. **Левый лист {A}** — один объект, делить нечего.

**Дерево** $b_1$ **(глубина 2):**

```text
             [Площадь ≤ 40?]
             /             \
           Да               Нет
           /                 \
       −0.333          [Площадь ≤ 60?]
                        /           \
                      Да             Нет
                      /               \
                  +0.667            +0.167
                    (B)            (C, D)
```

**Что записали в листья:**

- A → **−0.333**
- B → **+0.667**
- C, D → среднее $= \dfrac{-0.333 + 0.667}{2} = $ **+0.167**

### **Дерево для класса 2 (столбец** $g_2$**)**

| **Объект** | **Площадь** | **Цель** $g_2$ |
|----|----|----|
| A | 30 | −0.333 |
| B | 50 | −0.333 |
| C | 70 | **+0.667** |
| D | 90 | −0.333 |

**Цель:** $g_2 = [-0.333,\ -0.333,\ +0.667,\ -0.333]$.

**Идеально** — выделить C. Но C **посередине**. Одним порогом не выделить → берём **глубину 2**.

**Уровень 1 — корень.** Цели: $-0.333$, $-0.333$, $+0.667$, $-0.333$. Дисперсия в корне $= 0.1875$.

| **Сплит** | **Слева** | **Справа** | $H$ |
|----|----|----|----|
| ≤ 40? | {A} | {B, C, D} | $\frac{1}{4}\cdot 0 + \frac{3}{4}\cdot 0.222 = 0.167$ |
| ≤ 60? | {A, B} | {C, D} | $\frac{2}{4}\cdot 0 + \frac{2}{4}\cdot 0.25 = $ **0.125** |
| ≤ 80? | {A, B, C} | {D} | $\frac{3}{4}\cdot 0.222 + \frac{1}{4}\cdot 0 = 0.167$ |

Лучший — **«≤ 60?»** (как и у пня).

**Уровень 2.**

- **Левый лист {A, B}:** цели $-0.333$, $-0.333$ — уже **чистый**. Не делим.
- **Правый лист {C, D}:** цели $+0.667$, $-0.333$. Сплит «≤ 80?» → {C} и {D}, $H = 0$. **Идеально!**

**Дерево** $b_2$ **(глубина 2):**

```text
             [Площадь ≤ 60?]
             /             \
           Да               Нет
           /                 \
       −0.333          [Площадь ≤ 80?]
       (A, B)           /           \
                      Да             Нет
                      /               \
                  +0.667            −0.333
                    (C)               (D)
```

**Что записали в листья:**

- A, B → **−0.333**
- C → **+0.667**
- D → **−0.333**

> **Почему у классов 1 и 2 дерево глубины 2, а у класса 0 — только пень?** Потому что дерево класса 0 разделило антиградиенты **идеально уже на первом пороге** (листья чистые), а деревьям классов 1 и 2 одного порога мало. Дерево строит сплиты **пока есть смысл** (пока не достигнут `max_depth`). Что дали бы **пни** (глубина 1) — для сравнения показано ниже, в «**Дополнении**».

**Разница:**

- **MSE:** **1 дерево** на итерации.
- **Классификация:** $K$ **деревьев** (по числу классов).

# **ШАГ 3. Обновляем предсказания**

## **MSE**

**Формула:**

$$
a^{(1)} = a^{(0)} + \eta \cdot b_1
$$

$\eta = 1.0$ (для простоты).

| **Квартира** | $a^{(0)}$ | $b_1$ | $a^{(1)}$ |
|----|----|----|----|
| A | 0 | +5.0 | **5.0** |
| B | 0 | +5.0 | **5.0** |
| C | 0 | +9.5 | **9.5** |
| D | 0 | +9.5 | **9.5** |

**Одно число** на объект.

## **Классификация**

### **Формула**

Для **каждого** объекта и **каждого** класса:

$$
z_k^{\mathrm{new}} = z_k^{\mathrm{old}} + \eta \cdot b_k
$$

- $z_k^{\mathrm{old}}$ — **старый** логит (в начале все нули).
- $b_k$ — **предсказание дерева** для класса $k$ (значение из листа, куда попал объект).
- $\eta = 0.1$ — learning rate.
- $z_k^{\mathrm{new}}$ — **новый** логит.

**Важно:** обновляем **все** логиты **одновременно**, используя **предсказания деревьев**, полученные на шаге 2.

**Стало:** $1.625$. **Loss сильно уменьшился!**

# **ДОПОЛНЕНИЕ. Что дали бы пни (глубина 1)**

Выше деревья классов 1 и 2 имели **глубину 2**. Пень (глубина 1) — это не правило бустинга, а **гиперпараметр** (`max_depth`). Обычно берут глубину 3–8. Посмотрим, что дали бы **пни**, чтобы увидеть выигрыш от глубины 2.

Антиградиенты те же (шаг 1). Меняются только деревья — а значит, $b_k$, логиты, вероятности и loss.

## **Вывод**

| | **Пни (глубина 1)** | **Глубина 2 (наш случай)** |
|----|----|----|
| Дерево класса 0 | Идеально | То же самое |
| Дерево класса 1 | {A} \| {B, C, D} | {A} \| {B} \| {C, D} — лучше, но не идеально |
| Дерево класса 2 | {A, B} \| {C, D} | {A, B} \| {C} \| {D} — **идеально** |
| Средний loss после 1 итерации | 1.0615 | **1.0453** |

- **Деревья классов 1 и 2 выигрывают от глубины 2.**
- Глубже дерево → **точнее** приближает антиградиент → loss падает **быстрее** за итерацию.
- Но глубина — это **риск переобучения**: на 4 объектах глубокое дерево просто «запоминает» каждый объект. Поэтому глубину ограничивают (`max_depth`), а точность добирают **числом итераций** $M$ и маленьким $\eta$.
- Жадное построение **не гарантирует** лучшее дерево данной глубины (в нашем случае дерево класса 1 оставило C и D в одном листе, хотя идеальное дерево глубины 2 существует — нужна **глубина 3**).
- В MSE-части то же самое: на остатках $[+4,\ +6,\ +8,\ +11]$ дерево глубины 2 разделило бы все 4 квартиры.

# **Полная параллельная схема**

| **Шаг** | **MSE** | **Классификация** |
|----|----|----|
| **0** | $a^{(0)} = 0$ (1 число) | $z_k^{(0)} = 0$ ($K$ чисел) |
| **0.5** | — | Softmax → $a_k$ |
| **1** | $g_i = y_i - a_i$ | $g_k = y_k - a_k$ |
| **2** | **1 дерево** | $K$ **деревьев** (по классам) |
| **3** | $a \leftarrow a + \eta \cdot b$ | $z_k \leftarrow z_k + \eta \cdot b_k$ |
| **4** | — | Softmax → новые $a_k$ |
| **5** | Loss $= (y - a)^2$ | Loss $= -\log(a_y)$ |
| **Повтор** | $M$ раз | $M$ раз |

# **Что у нас есть в самом конце обучения**

## **MSE (регрессия)**

### **Короткий ответ**

**Набор деревьев** — все деревья, которые мы построили за M итераций. **И всё.** Никаких «итоговых предсказаний» для новых квартир **заранее** не считается — они **вычисляются** при появлении новой квартиры.

### **Что именно «лежит на складе»**

| **Что** | **Сколько** | **Пример** |
|----|----|----|
| **Деревья** | M | 100 деревьев |
| **Значение $\eta$** | 1 | 0.1 |
| **Начальное предсказание** | 1 | $a^{(0)} = 0$ |

**Итого:** **M деревьев** (например, 100) + $\eta$ + начальное предсказание.

### **Что не хранится**

**Итоговые предсказания** для **новых** квартир **не хранятся**. Они **вычисляются** в момент предсказания.

**Предсказания** для **обучающих** квартир — **были** в процессе обучения, но **не нужны** после.

**Сохраняем только деревья.**

### **Что происходит, когда приходит новая квартира**

**Прогоняем** её через **все** деревья и **складываем**:

$$
a(x) = 0 + \eta \cdot b_1(x) + \eta \cdot b_2(x) + \ldots + \eta \cdot b_M(x)
$$

**Получаем 1 число** — цену. **Это и есть предсказание.**

---

## **Классификация**

### **Короткий ответ**

**Набор деревьев** — все деревья, которые мы построили за M итераций. **И всё.** Никаких «итоговых логитов» для новых квартир **заранее** не считается — они **вычисляются** при появлении новой квартиры.

### **Что именно «лежит на складе»**

| **Что** | **Сколько** | **Пример** |
|----|----|----|
| **Деревья для класса 0** | M | 100 деревьев |
| **Деревья для класса 1** | M | 100 деревьев |
| **Деревья для класса 2** | M | 100 деревьев |
| **Значение $\eta$** | 1 | 0.1 |
| **Начальные логиты** | K | $[0, 0, 0]$ |

**Итого:** **K·M деревьев** (например, 300) + $\eta$ + начальные логиты.

### **Что не хранится**

**Итоговые логиты** для **новых** квартир **не хранятся**. Они **вычисляются** в момент предсказания.

**Логиты** для **обучающих** квартир — **были** в процессе обучения, но **не нужны** после.

**Сохраняем только деревья.**

### **Что происходит, когда приходит новая квартира**

**Прогоняем** её через **все** деревья и **складываем**:

**Для класса 0:**

$$
z_0 = 0 + \eta \cdot b_{0,1}(x) + \eta \cdot b_{0,2}(x) + \ldots + \eta \cdot b_{0,M}(x)
$$

**Для класса 1:**

$$
z_1 = 0 + \eta \cdot b_{1,1}(x) + \ldots + \eta \cdot b_{1,M}(x)
$$

**Для класса 2:**

$$
z_2 = 0 + \eta \cdot b_{2,1}(x) + \ldots + \eta \cdot b_{2,M}(x)
$$

**Получаем K логитов.** Потом **softmax** → вероятности → **предсказание**.

---

## **Сравнение — что хранится после обучения**

|    | **MSE** | **Классификация** |
|----|----|----|
| **Сколько деревьев** | **M** | **K·M** |
| **Что ещё хранится** | $\eta$, начальное предсказание | $\eta$, начальные логиты |
| **Что хранится в дереве** | Среднее **остатков** | Среднее **антиградиентов** |
| **Что вычисляем при предсказании** | 1 число (сумма) | K логитов (K сумм) |
| **Что после сумм** | Ничего — готово | **Softmax** → вероятности |
| **Что в итоге** | Цена (число) | K вероятностей → **argmax** |
