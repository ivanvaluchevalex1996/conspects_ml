> Loss — это ошибка на одном объекте. Эмпирический риск — это средняя ошибка по всем объектам (сумма всех Loss'ов, делённая на их количество).

[Пример расчетов](https://ivan-valuchev.yonote.ru/doc/primer-raschetov-hLZPMP9qh5)

---

### 1. ТРИ ГЛАВНЫХ ПОНЯТИЯ

| Понятие | Суть | На скольких объектах |
|:---|:---|:---|
| Loss | Штраф за один ответ модели | На одном объекте |
| Эмпирический риск ($R_{\text{emp}}$) | Средний штраф по всем объектам | На всех объектах |
| Обучение | Поиск параметров $\theta$, при которых $R_{\text{emp}}$ минимален | — |

---

### 2. ФОРМУЛЫ (ЗАПОМНИТЬ)

**Loss на одном объекте:**

$$
L(y, \hat{y}) - \text{любая функция (квадрат, модуль, логарифм, hinge)}
$$

[Пояснение, почему она не универсальна](https://ivan-valuchev.yonote.ru/doc/poyasnenie-pochemu-ona-ne-universalna-ncueWc0FW8)

**Эмпирический риск (универсальная формула):**

$$
R_{\text{emp}}(\theta) = \frac{1}{n} \sum_{i=1}^{n} L(y_i, \hat{y}_{\theta}(x_i))
$$

**Обучение (главная формула ML):**

$$
\theta_{\text{best}} = \arg \min_{\theta} R_{\text{emp}}(\theta)
$$

---

### 3. ВИДЫ LOSS (ДЛЯ РАЗНЫХ ЗАДАЧ)

| Loss | Формула | Для чего |
|:---|:---|:---|
| Squared | $(y - \hat{y})^2$ | Регрессия (сильно штрафует за большие ошибки) |
| Absolute | $|y - \hat{y}|$ | Регрессия с выбросами (штрафует линейно) |
| Log Loss | $-y \log(\hat{y}) - (1-y) \log(1-\hat{y})$ | Бинарная классификация (штраф за уверенные ошибки) |
| Hinge | $\max(0, 1 - y \cdot \hat{y})$ | SVM (штраф за недостаточную уверенность) |

---

### 4. ОПТИМИЗАТОРЫ (КТО КРУТИТ ПАРАМЕТРЫ)

| Метод | Как работает |
|:---|:---|
| Градиентный спуск | Идём в сторону уменьшения градиента (производной) |
| Adam, RMSprop | Адаптивные версии градиентного спуска (подстраивают шаг) |
| Аналитический метод | Решаем уравнение за один шаг (только для линейной регрессии) |
| Метод Ньютона | Используем вторую производную (быстрее, но дорого) |
| Градиентный бустинг | Добавляем деревья, каждое исправляет ошибки предыдущего |
| Безградиентные методы | Перебор, генетика, случайный поиск (когда нет производной) |

---

### 5. КЛЮЧЕВОЕ РАЗЛИЧИЕ

|    | Loss | Эмпирический риск |
|:---|:---|:---|
| **Это** | Штраф за один объект | Средний штраф по всем объектам |
| **Формула** | $L(y, \hat{y})$ | $\frac{1}{n} \sum L(y_i, \hat{y}_i)$ |
| **Пример** | $(7\,000\,000 - 6\,200\,000)^2$ | $\frac{640 + 90 + 160}{3} = 296.7$ млрд |

---

### 6. ПАРАМЕТРЫ vs ГИПЕРПАРАМЕТРЫ

|    | Параметры ($\theta$) | Гиперпараметры |
|:---|:---|:---|
| **Что это** | Веса, которые учит модель | Настройки, которые подбирает человек |
| **Примеры** | Коэффициенты регрессии, веса нейросети | $K$ в KNN, скорость обучения $\eta$ |
| **Как ищутся** | Автоматически (оптимизатором) | Вручную (перебором) |
| **Есть ли в KNN** | ❌ Нет | ✅ Да ($K$) |

---

### 7. ГЛАВНЫЙ ВЫВОД (ОДНОЙ ФРАЗОЙ)

**Loss — это штраф за один ответ. Эмпирический риск — средний штраф по всем ответам. Обучение — это поиск параметров, при которых средний штраф минимален. А оптимизатор решает, как именно менять параметры, чтобы этот штраф уменьшить.**

---

### 8. МЕТАФОРА (ДЛЯ ЗАПОМИНАНИЯ)

| Компонент | Аналогия |
|:---|:---|
| Loss | Штраф за одно неправильное решение на экзамене |
| Эмпирический риск | Средний балл за все экзамены |
| Обучение | Процесс подготовки, чтобы средний балл стал выше |
| Оптимизатор | Стратегия подготовки (учить всё подряд, повторять сложные темы, зубрить) |

---

### 9. ЧТО ЗАПОМНИТЬ НАВСЕГДА (6 ПРАВИЛ)

| № | Правило |
|:---|:---|
| 1 | Loss — всегда на одном объекте. |
| 2 | Эмпирический риск — всегда средний по всем объектам. |
| 3 | Формула риска универсальна: внутри можно подставить любой Loss. |
| 4 | Параметры $\theta$ есть не у всех моделей (у KNN их нет). |
| 5 | Градиентный спуск — не единственный оптимизатор. |
| 6 | Гиперпараметры (например, $K$) подбираются вручную, модель их не учит. |
