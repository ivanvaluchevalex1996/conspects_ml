## 📌 Одна фраза

> `randn` создаёт массив **случайных чисел из нормального распределения** (среднее 0, разброс \~1) — в домашке ими **инициализируют веса W** перед обучением.

---

## 🔷 Что делает

```python
np.random.randn()              →  одно число (float)
np.random.randn(5)             →  5 случайных чисел
np.random.randn(3, 2)          →  матрица 3×2 случайных чисел
```

Числа **разные каждый запуск** (если не зафиксировать seed).

Типичный вид: положительные и отрицательные, около нуля:

```
[-0.23,  1.05, -0.87,  0.41, -1.12]
```

| свойство | значение |
|:---|:---|
| распределение | **нормальное** (гауссово) |
| среднее | около **0** |
| типичный разброс | большинство чисел между **-2** и **+2** |
| форма | как у `ones` / `zeros` — число или кортеж |

> 💡 **randn** = **rand** + **n** (normal). Не путать с `np.random.rand` — там **равномерное** от 0 до 1.

---

## 🔷 Где в домашке

**Файл:** `linear_classifer.py` → `fit()` → инициализация `W`

```python
self.W = 0.001 * np.random.randn(num_features, num_classes)
#         ↑              ↑                    ↑
#      уменьшаем    случайные числа    (3073, 10)
```

| часть | смысл |
|:---|:---|
| `randn(3073, 10)` | случайная матрица весов |
| `0.001 * ...` | делаем числа **маленькими** |
| `if self.W is None` | только при **первом** запуске fit, не каждую эпоху |

После инициализации W **учится** градиентным спуском — `randn` только **стартовая точка**.

---

## 🔷 Зачем случайные веса, а не нули

| старт | проблема |
|:---|:---|
| `W = 0` | все классы одинаковы → градиенты симметричны → модель **не различает** цифры |
| `W = randn` | веса разные → логиты разные → softmax и градиент **оживают** |

> Связь с конспектом: градиентный спуск нужна **начальная точка**, откуда идти к минимуму loss. Нули — «застряли на плато».

---

## 🔷 Зачем умножать на 0.001

`randn` даёт числа порядка **±1** (иногда ±2–3).

Если W большие → логиты `X @ W` **огромные** → softmax → почти one-hot → градиенты **кривые**, обучение нестабильное.

```
W ~ randn           →  логиты ~ сотни
W ~ 0.001 * randn   →  логиты ~ доли единицы  →  мягкий softmax на старте
```

> ⚠️ **0.001** — эвристика «маленький старт». В ноутбуке `learning_rate` тоже подбирают (1e-3, 1e-7…).

---

## 🔷 Синтаксис

```
np.random.randn(d0, d1, d2, ...)
```

| вызов | shape | пример размеров |
|:---|:---|:---|
| `randn()` | скаляр | одно число |
| `randn(10)` | `(10,)` | вектор |
| `randn(3073, 10)` | `(3073, 10)` | W в SVHN |

> ⚠️ `randn(3073, 10)` — два аргумента = **две оси**.
>
> `randn((3073, 10))` — **тоже ок** (кортеж одним аргументом).

---

## 🔷 randn vs rand vs randint

| функция | что выдаёт | диапазон / тип |
|:---|:---|:---|
| `randn(...)` | нормальное распределение | \~(-3, +3), float |
| `rand(...)` | равномерное | **[0, 1)**, float |
| `randint(a, b, size=...)` | целые случайные | **[a, b)**, int |

В домашке:

- **W** — `randn` (вещественные веса)
- тесты в ноутбуке — часто `randint` (просто заглушки для check_gradient)

## 🔷 Пример на цифрах

```python
np.random.seed(42)   # чтобы числа повторялись (для отладки)
W_raw = np.random.randn(2, 3)
```

Возможный результат (2 признака × 3 класса):

```
[[ 0.05, -1.23,  0.88],
 [ 0.67, -0.34,  1.01]]
```

С `0.001`:

```
[[ 0.00005, -0.00123,  0.00088],
 [ 0.00067, -0.00034,  0.00101]]
```

30730 таких чисел в полной W `(3073, 10)` — каждый вес стартует **маленьким и случайным**.

---

## 🔷 seed — воспроизводимость

```python
np.random.seed(42)
W1 = np.random.randn(3, 2)
np.random.seed(42)
W2 = np.random.randn(3, 2)
# W1 и W2 одинаковые
```

Без seed — каждый запуск fit другие стартовые W → accuracy чуть плавает. Для отладки seed полезен.

---

## 🔷 Связь с fit()

```
fit() первый раз:
  W = 0.001 * randn(3073, 10)   ← старт

каждый батч:
  W = W - lr * grad              ← W уже не randn, а обученные веса
```

`randn` **не вызывают** каждую эпоху — только если `self.W is None`.

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `randn` — случайные float из **нормального** распределения (\~0, \~±1) |
| 2 | В домашке — **инициализация W** перед обучением |
| 3 | `0.001 * randn` — маленький старт, стабильный softmax |
| 4 | Не нули — иначе все классы одинаковы на старте |
| 5 | Форма W: `(num_features, num_classes)` = `(3073, 10)` |
| 6 | Не путать: `randn` (normal) ≠ `rand` (0..1) ≠ `randint` (целые) |
| 7 | Один раз в fit; дальше W меняет только градиентный спуск |
