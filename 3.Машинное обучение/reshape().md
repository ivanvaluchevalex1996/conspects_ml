## 📌 Одна фраза

> `reshape` **меняет форму** массива, не трогая сами числа — в домашке: картинка `(32, 32, 3)` → строка из `3072` пикселей.

---

## 🔷 Что делает

```python
a.reshape(новая_форма)     # метод массива
np.reshape(a, новая_форма) # то же функцией
```

Числа **те же**, меняется только «как разложены по осям».

| до | после reshape | смысл |
|:---|:---|:---|
| `(2, 3)` | `(3, 2)` или `(6,)` | те же 6 чисел, другая раскладка |
| `(N, 32, 32, 3)` | `(N, 3072)` | N картинок → N строк признаков |

> ⚠️ Число элементов **не меняется**: `до.size == после.size`. Иначе ошибка.

---

## 🔷 Зачем в домашке

Линейный классификатор и KNN ждут **таблицу**: строка = объект, столбцы = признаки.

Картинка SVHN — **3D** (высота × ширина × RGB), не строка. Нужно **сплющить**:

```python
# Linear classifier.ipynb → prepare_for_linear_classifier
train_flat = train_X.reshape(train_X.shape[0], -1).astype(np.float64) / 255.0
```

То же в `KNN.ipynb`:

```python
train_X = train_X.reshape(train_X.shape[0], -1)
```

Цепочка:

```
картинка  (32, 32, 3)     32×32 пикселя × 3 цвета
    ↓ reshape(N, -1)
плоская   (N, 3072)       одна строка = все пиксели подряд
    ↓ / 255.0
числа 0..1
    ↓ hstack + ones
(N, 3073)                 + bias (столбец единиц)
```

| shape | смысл |
|:---|:---|
| `train_X.shape[0]` | N — сколько картинок **оставить** |
| `-1` | «посчитай сам» вторую ось: `32*32*3 = 3072` |

---

## 🔷 Синтаксис и `-1`

```
массив.reshape(d0, d1, ...)
массив.reshape((d0, d1, ...))
```

| параметр | смысл |
|:---|:---|
| числа `d0, d1, ...` | новые размеры по осям |
| `-1` | **одна** ось: numpy сам посчитает длину |

```python
a = np.arange(12)          # shape (12,)
a.reshape(3, 4)            # (3, 4)
a.reshape(2, -1)           # (2, 6)  — 12/2 = 6
a.reshape(-1, 3)           # (4, 3)  — 12/3 = 4
```

> В домашке: `reshape(N, -1)` = «N строк, столбцов сколько получится».

---

## 🔷 Пример на цифрах

2 «картинки» 2×2×1 (упрощённо, без RGB):

```
train_X shape (2, 2, 2, 1):

картинка 0:  [[1, 2],
              [3, 4]]
картинка 1:  [[5, 6],
              [7, 8]]
```

```python
flat = train_X.reshape(train_X.shape[0], -1)
# shape (2, 4)
#
# [[1, 2, 3, 4],
#  [5, 6, 7, 8]]
```

Порядок: по строкам слева направо, сверху вниз (C-order по умолчанию).

SVHN по масштабу:

```
(9000, 32, 32, 3)  →  reshape(9000, -1)  →  (9000, 3072)
                              ↑
                         32*32*3 = 3072
```

## 🔷 Связь с shape

|    |    |
|:---|:---|
| `.shape` | **смотреть** размеры |
| `.reshape(...)` | **менять** размеры |

Правило: произведение размеров до = произведению после.

```
(2, 3, 4) → size 24
reshape(6, 4) ✓
reshape(5, 5) ✗  — 25 ≠ 24
```

> См. также: `shape().md` — там `reshape(n, -1)` в таблице «shape после операций».

## 🔷 Частые ошибки

| ошибка | почему |
|:---|:---|
| `reshape(3072)` на батч картинок | схлопнет **все** картинки в один вектор |
| забыть `-1` / `shape[0]` | нужна **N строк**, не одна каша |
| `reshape(N, 3072)` при другом размере картинки | упадёт, если пикселей не 3072 |
| путать с `resize` | `resize` **может** менять число элементов — в домашке нужен `reshape` |

Правильно для домашки:

```python
X.reshape(X.shape[0], -1)   # каждая картинка → своя строка
```

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `reshape` меняет **форму**, не сами числа |
| 2 | `size` до и после должен совпасть |
| 3 | `-1` = «посчитай эту ось сам» |
| 4 | В домашке: `(N, 32, 32, 3) → (N, 3072)` через `reshape(N, -1)` |
| 5 | Потом `/255`, mean, `ones` → `(N, 3073)` для линейного классификатора |
| 6 | Не сплющивать весь датасет в 1D — оставляй `shape[0]` = число объектов |
