## 📌 Одна фраза

> `.ndim` — **сколько измерений** у массива: 1 = вектор, 2 = таблица (батч), 4 = пачка картинок.

---

## 🔷 Что делает

```python
a.ndim   # целое число: сколько осей
```

Это **не** функция: пишем `X.ndim`, не `ndim(X)`.

| массив | shape | ndim | как читать |
|:---|:---|:---|:---|
| вектор 10 классов | `(10,)` | **1** | одна ось |
| батч логитов | `(300, 10)` | **2** | строки × классы |
| одна картинка RGB | `(32, 32, 3)` | **3** | H × W × цвет |
| train SVHN | `(9000, 32, 32, 3)` | **4** | N × H × W × цвет |
| после flatten | `(9000, 3072)` | **2** | таблица признаков |

> `ndim == len(shape)` всегда.

---

## 🔷 Зачем в домашке

В `linear_classifer.py` (`softmax`, `cross_entropy_loss`, `softmax_with_cross_entropy`) тесты дают то **одну** картинку, то **батч**. Ветка по `ndim` выбирает ось:

```python
if predictions.ndim == 1:
    axis = 0   # вектор (10,) — одна картинка, одна ось
else:
    axis = 1   # таблица (batch, 10) — max/sum по классам внутри строки
```

То же для индексации в cross-entropy:

```python
if probs.ndim == 1:
    # одна картинка: взять probs[правильный_класс]
else:
    # батч: взять probs[строка, правильный_класс] по каждой картинке
```

| ndim | форма | что делаем |
|:---|:---|:---|
| 1 | `(10,)` | softmax `axis=0`; индекс `probs[y]` |
| 2 | `(batch, 10)` | softmax `axis=1`; индекс `probs[i, y[i]]` |

> Без проверки `ndim` код падает на 1D-тесте (`IndexError`) или считает softmax «вдоль не той оси».

Связь с `axis.md`: оси нумеруются `0 .. ndim-1`. Нет оси 1, если `ndim == 1`.

---

## 🔷 Пример на цифрах

```python
z1 = np.array([2.0, 1.0, 0.1])   # shape (3,),  ndim = 1
z2 = np.array([[2.0, 1.0, 0.1],
               [0.5, 2.0, 1.0]]) # shape (2, 3), ndim = 2
```

После `reshape` ndim меняется вместе с формой:

```
(9000, 32, 32, 3)  ndim=4
       ↓ reshape(9000, -1)
(9000, 3072)       ndim=2
```

## 🔷 ndim vs shape — не путать

| вопрос | смотри |
|:---|:---|
| Сколько осей? | `.ndim` → `1`, `2`, `4` |
| Какой размер по оси? | `.shape[0]`, `.shape[1]` |
| Одна картинка или батч (логиты)? | `ndim == 1` vs `ndim == 2` |
| Сколько картинок в батче? | `shape[0]` (когда `ndim == 2`) |

```
(10,)     ndim=1  — не «10 осей», а 1 ось длины 10
(10, 1)   ndim=2  — уже таблица (столбец)
```

> ⚠️ `(10,)` и `(10, 1)` — разный `ndim` → разный код для softmax / индексов.

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `.ndim` = число осей = `len(shape)` |
| 2 | 1D логиты → `axis=0`; 2D батч → `axis=1` |
| 3 | В домашке: `if x.ndim == 1: ... else: ...` |
| 4 | После flatten картинок `ndim` с 4 → 2 |
| 5 | `(10,)` ≠ `(10, 1)` — разный ndim |
| 6 | Вместе с `.shape` и `axis` — см. `shape().md`, `axis.md` |
