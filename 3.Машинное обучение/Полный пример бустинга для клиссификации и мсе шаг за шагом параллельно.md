Будем идти **параллельно**. Ты увидишь: **идея одна**, просто в классификации **повторяется $K$ раз**.

---

## **Данные**

### **MSE (регрессия)**

**4 квартиры.** Предсказываем **цену**.

| **Квартира** | **Площадь** | **Цена (истина)** |
|----|----|----|
| A | 30 | 4.0 |
| B | 50 | 6.0 |
| C | 70 | 8.0 |
| D | 90 | 11.0 |

### **Классификация**

**Те же 4 квартиры.** Предсказываем **класс** (0, 1, 2).

| **Квартира** | **Площадь** | **Класс (истина)** |
|----|----|----|
| A | 30 | 0 |
| B | 50 | 1 |
| C | 70 | 2 |
| D | 90 | 1 |

---

# **ШАГ 0. Начальное состояние**

## **MSE**

**Ничего не знаем.** Ставим **одно** число: $a^{(0)} = 0$ для **всех**.

| **Квартира** | $a^{(0)}$ |
|----|----|
| A | 0 |
| B | 0 |
| C | 0 |
| D | 0 |

## **Классификация**

**Ничего не знаем.** Ставим **$K$ логитов**: $z_k^{(0)} = 0$ для **всех** классов и объектов. **$K = 3$.**

| **Квартира** | $z_0$ | $z_1$ | $z_2$ |
|----|----|----|----|
| A | 0 | 0 | 0 |
| B | 0 | 0 | 0 |
| C | 0 | 0 | 0 |
| D | 0 | 0 | 0 |

**Разница:**

- **MSE:** **1 число** на объект.
- **Классификация:** **$K$ чисел** на объект (по одному на класс).

---

# **ШАГ 0.5. Softmax (только в классификации)**

## **MSE**

**Нет softmax.** Логиты — **уже** финальное предсказание. $a = 0$.

## **Классификация**

**Нужен softmax** — превратить логиты в **вероятности**.

**Для каждого объекта** применяем softmax к $[0,\ 0,\ 0]$:

$$
a_k = \frac{e^{0}}{e^{0} + e^{0} + e^{0}} = \frac{1}{3}
$$

| **Квартира** | $a_0$ | $a_1$ | $a_2$ |
|----|----|----|----|
| A | 0.333 | 0.333 | 0.333 |
| B | 0.333 | 0.333 | 0.333 |
| C | 0.333 | 0.333 | 0.333 |
| D | 0.333 | 0.333 | 0.333 |

**Смысл:** модель даёт **по $1/3$** на каждый класс.

**Разница:**

- **MSE:** softmax **не нужен**.
- **Классификация:** softmax **обязателен** — переводит логиты в вероятности.

# **ШАГ 1. Считаем антиградиенты**

## **MSE**

**Формула:**

$$
g_i = y_i - a_i^{(0)}
$$

| **Квартира** | $y$ | $a^{(0)}$ | $g^{(1)}$ |
|----|----|----|----|
| A | 4.0 | 0 | **+4.0** |
| B | 6.0 | 0 | **+6.0** |
| C | 8.0 | 0 | **+8.0** |
| D | 11.0 | 0 | **+11.0** |

**Одно число на объект.**

## **Классификация**

**Формула:**

$$
g_k = y_k - a_k
$$

**One-hot для истины:**

- A (истина 0): $[1,\ 0,\ 0]$
- B (истина 1): $[0,\ 1,\ 0]$
- C (истина 2): $[0,\ 0,\ 1]$
- D (истина 1): $[0,\ 1,\ 0]$

**Считаем** $g_k = y_k - a_k$:

**A** ($y = [1,0,0]$, $a = [0.333, 0.333, 0.333]$):

$$
g_A = [+0.667,\ -0.333,\ -0.333]
$$

**B** ($y = [0,1,0]$):

$$
g_B = [-0.333,\ +0.667,\ -0.333]
$$

**C** ($y = [0,0,1]$):

$$
g_C = [-0.333,\ -0.333,\ +0.667]
$$

**D** ($y = [0,1,0]$):

$$
g_D = [-0.333,\ +0.667,\ -0.333]
$$

**Сводно:**

| **Квартира** | $g_0$ | $g_1$ | $g_2$ |
|----|----|----|----|
| A | **+0.667** | −0.333 | −0.333 |
| B | −0.333 | **+0.667** | −0.333 |
| C | −0.333 | −0.333 | **+0.667** |
| D | −0.333 | **+0.667** | −0.333 |

**$K$ чисел на объект.**

**Разница:**

- **MSE:** **1** антиградиент (число) на объект.
- **Классификация:** **$K$ антиградиентов** (по классам) на объект.

# **ШАГ 2. Строим деревья**

## **MSE**

**Одно дерево** $b_1$ на антиградиентах $[+4.0,\ +6.0,\ +8.0,\ +11.0]$.

**Цель:** предсказать эти числа.

**Ищем сплит:** «Площадь ≤ 60?»

- Слева (A, B): $+4.0$, $+6.0$. Среднее = **+5.0**.
- Справа (C, D): $+8.0$, $+11.0$. Среднее = **+9.5**.

**Дерево** $b_1$:

```text
        [Площадь ≤ 60?]
        /            \
      Да              Нет
      /                \
   +5.0              +9.5
```

## **Классификация**

**$K$ деревьев** — по одному на **каждый** класс.

### **Дерево для класса 0**

**Цель:** $g_0 = [+0.667,\ -0.333,\ -0.333,\ -0.333]$.

**Ищем сплит:** «Площадь ≤ 40?»

- Слева (A): $+0.667$.
- Справа (B, C, D): $-0.333$ (все три).

**Идеальный сплит.** Дерево $b_0$:

```text
        [Площадь ≤ 40?]
        /            \
      Да              Нет
      /                \
   +0.667           −0.333
```

### **Дерево для класса 1**

**Цель:** $g_1 = [-0.333,\ +0.667,\ -0.333,\ +0.667]$.

**Лучший сплит** (приближённый): «Площадь ≤ 40?»

- Слева (A): $-0.333$.
- Справа (B, C, D): среднее $= \dfrac{+0.667 - 0.333 + 0.667}{3} = +0.333$.

**Дерево** $b_1$:

```text
        [Площадь ≤ 40?]
        /            \
      Да              Нет
      /                \
   −0.333           +0.333
```

### **Дерево для класса 2**

**Цель:** $g_2 = [-0.333,\ -0.333,\ +0.667,\ -0.333]$.

**Лучший сплит:** «Площадь ≤ 60?»

- Слева (A, B): $-0.333$, $-0.333$. Среднее $= -0.333$.
- Справа (C, D): среднее $= \dfrac{+0.667 - 0.333}{2} = +0.167$.

**Дерево** $b_2$:

```text
        [Площадь ≤ 60?]
        /            \
      Да              Нет
      /                \
   −0.333           +0.167
```

**Разница:**

- **MSE:** **1 дерево** на итерации.
- **Классификация:** **$K$ деревьев** (по числу классов).

# **ШАГ 3. Обновляем предсказания**

## **MSE**

**Формула:**

$$
a^{(1)} = a^{(0)} + \eta \cdot b_1
$$

**$\eta = 1.0$** (для простоты).

| **Квартира** | $a^{(0)}$ | $b_1$ | $a^{(1)}$ |
|----|----|----|----|
| A | 0 | +5.0 | **5.0** |
| B | 0 | +5.0 | **5.0** |
| C | 0 | +9.5 | **9.5** |
| D | 0 | +9.5 | **9.5** |

**Одно число** на объект.

## **Классификация**

**Формула:**

$$
z_k^{(1)} = z_k^{(0)} + \eta \cdot b_k
$$

**$\eta = 0.1$.**

**Для A** (площадь 30):

- Дерево 0: $30 \le 40$ → $+0.667$.
- Дерево 1: $30 \le 40$ → $-0.333$.
- Дерево 2: $30 \le 60$ → $-0.333$.

| **Класс** | $z_k^{(0)}$ | $b_k$ | $z_k^{(1)} = z_k^{(0)} + 0.1 \cdot b_k$ |
|----|----|----|----|
| 0 | 0 | +0.667 | **+0.0667** |
| 1 | 0 | −0.333 | **−0.0333** |
| 2 | 0 | −0.333 | **−0.0333** |

**Для B** (площадь 50):

- Дерево 0: $50 > 40$ → $-0.333$.
- Дерево 1: $50 > 40$ → $+0.333$.
- Дерево 2: $50 \le 60$ → $-0.333$.

| **Класс** | $z_k^{(0)}$ | $b_k$ | $z_k^{(1)}$ |
|----|----|----|----|
| 0 | 0 | −0.333 | **−0.0333** |
| 1 | 0 | +0.333 | **+0.0333** |
| 2 | 0 | −0.333 | **−0.0333** |

**Для C** (площадь 70):

- Дерево 0: $70 > 40$ → $-0.333$.
- Дерево 1: $70 > 40$ → $+0.333$.
- Дерево 2: $70 > 60$ → $+0.167$.

| **Класс** | $z_k^{(1)}$ |
|----|----|
| 0 | **−0.0333** |
| 1 | **+0.0333** |
| 2 | **+0.0167** |

**Для D** (площадь 90):

- Дерево 0: $90 > 40$ → $-0.333$.
- Дерево 1: $90 > 40$ → $+0.333$.
- Дерево 2: $90 > 60$ → $+0.167$.

| **Класс** | $z_k^{(1)}$ |
|----|----|
| 0 | **−0.0333** |
| 1 | **+0.0333** |
| 2 | **+0.0167** |

**$K$ логитов** на объект.

**Разница:**

- **MSE:** обновляем **1 число**.
- **Классификация:** обновляем **$K$ логитов**.

# **ШАГ 4. Новый softmax (только классификация)**

## **MSE**

**Нет softmax.** Предсказание **готово**: $[5.0,\ 5.0,\ 9.5,\ 9.5]$.

## **Классификация**

**Применяем softmax** к новым логитам.

**Для A** логиты $[+0.0667,\ -0.0333,\ -0.0333]$:

- Максимум: $0.0667$.
- Вычитаем: $[0,\ -0.1,\ -0.1]$.
- Exp: $[1.0,\ 0.9048,\ 0.9048]$.
- Сумма: $2.8096$.
- Вероятности: $[0.356,\ 0.322,\ 0.322]$.

**Смысл:** вероятность класса 0 **выросла** с $0.333$ до $0.356$.

**Разница:**

- **MSE:** после обновления — **готово**.
- **Классификация:** после обновления — **softmax** → вероятности.

# **ШАГ 5. Считаем loss**

## **MSE**

**Loss:** $(y - a)^2$.

$$
\begin{align*}
A&:\ (4.0 - 5.0)^2 = 1.0 \\
B&:\ (6.0 - 5.0)^2 = 1.0 \\
C&:\ (8.0 - 9.5)^2 = 2.25 \\
D&:\ (11.0 - 9.5)^2 = 2.25
\end{align*}
$$

**Средний loss:**

$$
\frac{1.0 + 1.0 + 2.25 + 2.25}{4} = 1.625
$$

**Было:** $a^{(0)} = 0$. Loss $= \dfrac{16 + 36 + 64 + 121}{4} = 59.25$.

**Стало:** $1.625$. **Loss сильно уменьшился!**

## **Классификация**

**Loss:** $-\log(a_y)$.

**Для A** (истина 0, $a_0 = 0.356$):

$$
-\log(0.356) = 1.033
$$

**Было** (при $a = 1/3$):

$$
-\log(0.333) = 1.099
$$

**Стало:** $1.033$. **Loss уменьшился.**

**Разница:**

- **MSE:** loss $= (y - a)^2$.
- **Классификация:** loss $= -\log(a_y)$.

**Общее:** в обоих случаях loss **уменьшается** с каждой итерацией.

# **Полная параллельная схема**

| **Шаг** | **MSE** | **Классификация** |
|----|----|----|
| **0** | $a^{(0)} = 0$ (1 число) | $z_k^{(0)} = 0$ ($K$ чисел) |
| **0.5** | — | Softmax → $a_k$ |
| **1** | $g_i = y_i - a_i$ | $g_k = y_k - a_k$ |
| **2** | **1 дерево** | **$K$ деревьев** (по классам) |
| **3** | $a \leftarrow a + \eta \cdot b$ | $z_k \leftarrow z_k + \eta \cdot b_k$ |
| **4** | — | Softmax → новые $a_k$ |
| **5** | Loss $= (y - a)^2$ | Loss $= -\log(a_y)$ |
| **Повтор** | $M$ раз | $M$ раз |

# **Три ключевых отличия**

### **Отличие 1. Сколько чисел**

- **MSE:** **1 число** на объект.
- **Классификация:** **$K$ чисел** на объект.

### **Отличие 2. Сколько деревьев**

- **MSE:** **1 дерево** на итерации.
- **Классификация:** **$K$ деревьев** (по одному на класс).

### **Отличие 3. Softmax**

- **MSE:** **не нужен**.
- **Классификация:** **обязателен** — переводит логиты в вероятности.

**Всё остальное — одинаково.**

---

# **Сходство — что одно и то же**

| **Понятие** | **Одинаково** |
|----|----|
| **Идея** | Сумма деревьев, каждое чинит ошибки |
| **Антиградиент** | $y - a$ (в широком смысле) |
| **Формула обновления** | предсказание $+ \eta$ · дерево |
| **Loss уменьшается** | С каждой итерацией |
| **Дерево регрессионное** | Да — и там, и там |
| **Много итераций** | Сотни-тысячи |

---

# **Сводка**

**GBDT для классификации = GBDT для MSE**, но:

1. **$K$ чисел** вместо 1.
2. **$K$ деревьев** вместо 1.
3. **Softmax** после обновления.

**Алгоритм тот же.** Просто **повторяем** его **$K$ раз** — по одному на класс.
