# **Три ключевых отличия**

### **Отличие 1. Сколько чисел**

- **MSE:** **1 число** на объект.
- **Классификация:** **K чисел** на объект.

### **Отличие 2. Сколько деревьев**

- **MSE:** **1 дерево** на итерации.
- **Классификация:** **K деревьев** (по одному на класс).

### **Отличие 3. Softmax**

- **MSE:** **не нужен**.
- **Классификация:** **обязателен** — переводит логиты в вероятности.

**Всё остальное — одинаково.**

# **Сходство — что одно и то же**

| **Понятие** | **Одинаково** |
|----|----|
| **Идея** | Сумма деревьев, каждое чинит ошибки |
| **Антиградиент** | y−a*y*−*a* (в широком смысле) |
| **Формула обновления** | предсказание + η*η* · дерево |
| **Loss уменьшается** | С каждой итерацией |
| **Дерево регрессионное** | Да — и там, и там |
| **Много итераций** | Сотни-тысячи |
