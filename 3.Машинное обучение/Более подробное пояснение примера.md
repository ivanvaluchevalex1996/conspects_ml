## Аналогия с деньгами и корзинами

Представь, что у тебя есть три корзины: для кота, для собаки и для попугая. В каждой корзине лежат монеты. Ты хочешь, чтобы сумма монет в каждой корзине равнялась определённому числу (весу животного):

- Корзина кота = 5
- Корзина собаки = 7
- Корзина попугая = 3

У тебя есть монеты разных достоинств. Ты можешь добавлять монеты в каждую корзину по отдельности или одну общую монету, которая кладётся во все корзины одновременно.

### Первый случай (4 коэффициента)

У тебя есть:

- Общая монета ($w_0$) — её ты кладёшь во все корзины.
- Три специальные монеты: для кота ($w_c$), для собаки ($w_d$), для попугая ($w_p$). Ты можешь положить их только в соответствующую корзину.

Ты хочешь получить суммы:

- Кот: общая + специальная кота = 5
- Собака: общая + специальная собаки = 7
- Попугай: общая + специальная попугая = 3

Теперь, если ты возьмёшь общую монету = 100 (огромную), то чтобы в корзине кота получить 5, ты должен добавить специальную монету кота = -95 (отрицательную, т.е. ты забираешь монеты). Для собаки: специальная = -93. Для попугая: специальная = -97.

Итог:

- Кот: $100 + (-95) = 5$
- Собака: $100 + (-93) = 7$
- Попугай: $100 + (-97) = 3$

Все суммы верны! Ты можешь взять общую монету = 100, потому что у каждого животного есть своя специальная монета, которая компенсирует эту общую.

### Второй случай (3 коэффициента, удалён parrot)

Теперь у тебя нет специальной монеты для попугая. Есть только:

- Общая монета ($w_0'$) — кладётся во все корзины.
- Специальные монеты: для кота ($w_c'$) и для собаки ($w_d'$). Для попугая специальной нет.

Теперь, когда ты кладёшь общую монету, она попадает в корзину попугая без всякой компенсации, потому что нет специальной монеты, чтобы её скорректировать.

Ты хочешь:

- Попугай: общая = 3 (потому что других монет в его корзине нет)

Значит, общая монета обязана быть ровно 3. Если ты возьмёшь общую монету = 100, то в корзине попугая будет 100, а должно быть 3 — это неверно.

Ты не можешь изменить это, потому что у попугая нет рычага (специальной монеты), чтобы уменьшить сумму.

### Резюме

Можно взять $w_0 = 100$ в первом случае, потому что есть $w_p$, который компенсирует эту сотню для попугая. Нельзя во втором случае, потому что у попугая нет своего коэффициента, и $w_0'$ напрямую становится его предсказанием, которое обязано быть 3.
