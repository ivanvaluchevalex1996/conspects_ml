## 📌 0. Одна фраза

> **`@`** — **сжать** признаки в ответ модели (логит на строку). **`*`** — **по каждой ячейке** отдельно (таблица как X, нормализация, ошибка). Один нейрон: `X @ w` ≡ `(X * w).sum(axis=1)`; **без** `.sum` после `*` логита нет.

---

## 🔷 1. Главный вопрос перед строкой кода

**Спроси себя:**

«Мне нужна **таблица** того же размера, что X (у каждого объекта и признака своё число), или **короче**: одно (или h) чисел **на каждую строку** X?»

| Ответ | Операция | типичный shape |
|:---|:---|:---|
| таблица | `*` (+ broadcast), `-`, `/`, `**2` | `(m, d)` как у X |
| **одно число на объект** (логит z) | `X @ w + b` или `(X * w).sum(axis=1) + b` | `(m,)` |
| **h логитов на объект** (слой) | `X @ W + b`, W формы `(d, h)` | `(m, h)` |

Если сомневаешься — **напиши желаемый shape**:

- нужен **`(m,)`** или **`(m, h)`** → не оставайся на **`(m, d)`** без `sum(axis=1)` / без `@`
- в REPL: `print(out.shape)` — не сошлось с задумкой → неверный оператор

**Фразы-якоря:**

- `@` — «сжать признаки в ответ модели»
- `*` — «поиграть с каждой ячейкой» (вклады, маска, `(y-p)²`, нормализация)

## 🔷 2. Три операции: `*`, `@`, dot

| Запись | Имя | Зачем в ML |
|:---|:---|:---|
| `A * B` | поэлементно + broadcast | `(y-p)**2`, `X - mean`, `X * w` вклады |
| `A @ B` | матричное умножение | `X @ w`, `X @ W` |
| `np.dot(A, B)` | как `@` для 1D–2D; для 3D+ — осторожно | старый код; скаляр `dot(a,b)` |

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

a * b           # [4, 10, 18]  — три числа, НЕ одно
a @ b           # 32
np.dot(a, b)    # 32
```

**`np.dot` vs `@`:** в учёбе и Deep-ML для 1D–2D пиши **`X @ w`**; для 3D+ в DL надёжнее `@`, не `dot`.

## 🔷 3. `*` и broadcasting

`X (m, d) * w (d,)` → **`(m, d)`**: веса **растягиваются** на все строки (мысленно `w` → `(1, d)` → `(m, d)`). **Большой** массив задаёт «каркас», **меньший** повторяют, не наоборот.

```
X * w  →  таблица вкладов x_ij * w_j
```

Подробные правила осей — в конспекте **4**, broadcasting.

**`axis=1`:** схлопываем **столбцы** → **одно число на строку** (логит). Не «ось строка», а «сумма вдоль столбцов внутри каждой строки».

## 🔷 4. `@`: размеры и 4 случая

### Правило

```
A: (строки_A, столбцы_A)
B: (строки_B, столбцы_B)

столбцы_A == строки_B  →  результат (строки_A, столбцы_B)
```

Коротко: **`(A, B) @ (B, C) → (A, C)`**

### Мнемоника «сэндвич»

```
     ┌──── внутренние ────┐
   (m, n)    @    (n, p)   →   (m, p)
```

**Фраза:** «Средние совпали — крайние в результат». **Не** сравнивай 3 и 2 в `(3,2) @ (2,)` — сравни **2 и 2**.

### Четыре случая

| # | Выражение | Результат |
|:---|:---|:---|
| 1 | `(n,) @ (n,)` | скаляр |
| 2 | `(m, n) @ (n,)` | `(m,)` — **батч логитов**, Deep-ML #24 |
| 3 | `(m,) @ (m, n)` | `(n,)` |
| 4 | `(m, n) @ (n, p)` | `(m, p)` |

Пример **(2):**

```python
X = np.array([[1, 2], [3, 4], [5, 6]])   # (3, 2) — 3 объекта, 2 признака
w = np.array([1, 0.5])                     # (2,) — 2 веса
X @ w   # (3,)
```

Вектор `(n,)` в `@` — **не** «(n, 1)» в записи, но внутренний размер **n** должен совпасть со **столбцами** X.

### Что не проверять

| Мысль | Верно? |
|:---|:---|
| У A и B одинаковый shape | ❌ |
| Совпали только «первые» или «последние» числа | ❌ |

### Шаблон ML

```
(batch, features) @ (features, classes) → (batch, classes)
```

Пример: `X (9000, 3073) @ W (3073, 10) → (9000, 10)` — сравни **3073 == 3073**.

## 🔷 5. Один нейрон: `X*w` vs `X@w`

```python
X = np.array([[0.5, 1.0], [-1.5, -2.0], [2.0, 1.5]])   # (3, 2)
w = np.array([0.7, -0.4])                               # (2,)
b = -0.1

z1 = (X * w).sum(axis=1) + b   # (3,)
z2 = X @ w + b                 # (3,)
# np.allclose(z1, z2)
```

| Шаг | shape | логит? |
|:---|:---|:---|
| `X * w` | `(3, 2)` | нет |
| `.sum(axis=1)` | `(3,)` | да |
| `X @ w` | `(3,)` | да |
| `sigmoid(z)` | как у `z` | вероятности |

`(3, 2) @ (2, 1) → (3, 1)` — те же числа, **столбец**; для бинарки часто удобнее `(3,)`.

## 🔷 6. Сценарии ML

### 6.1 Forward (предсказание)

```python
z = X @ w + b      # (m,) — один нейрон
z = X @ W + b      # (m, h) — слой
p = 1 / (1 + np.exp(-z))
```

Не подавай в sigmoid **`X * w`** без `sum(axis=1)`.

### 6.2 Вклады (учёба)

```python
X * w              # (m, d) — смотреть, не финальный логит
```

### 6.3 Loss (уже есть p и y)

```python
(y - p) ** 2           # (m,)
((y - p) ** 2).mean() # MSE — одно число; не @
```

### 6.4 Данные

```python
X - X.mean(axis=0)     # (m, d)
X * mask               # (m, d)
```

### Шпаргалка «что в руках?»

| Данные | Параметр | Цель | Пиши |
|:---|:---|:---|:---|
| `X (m,d)` | `w (d,)` | логит на объект | `@` |
| `X (m,d)` | `W (d,h)` | h логитов | `@` |
| `X (m,d)` | `w (d,)` | таблица | `*` |
| `p (m,)`, `y (m,)` | — | MSE | `*`, `**2`, `mean` |
| `scores (k,)` | — | softmax **одного** объекта | `exp`, `/ sum` — не `X @ w` |

**Softmax:** длина **k** = число **классов одного** объекта; сумма вероятностей = 1. **m** вероятностей в батче — **m разных объектов**, их **не** складывают до 1.

## 🔷 7. Частые ошибки

```python
X * w                    # (m, d) — НЕ z
(y - p) ** 2 / n         # вектор — НЕ MSE
((y - p) ** 2).mean()    # MSE
np.round(p, 4).tolist()  # список вероятностей
round(float(mse), 4)     # один float для MSE
```

## 🔷 8. Алгоритм и путаницы

**10 секунд:**

1. `X.shape` и что справа (`w`, `W`, `y`, `p`).
2. Результат = **как X** (таблица) или **короче** (вектор на строку)?
3. Таблица → `*`; линейный слой → `@` (или `* + sum(axis=1)`).

| Кажется | На самом деле |
|:---|:---|
| «веса × признаки» → всегда `@` | только если нужен **итог на строку** |
| после `*` получил `(m,d)` → sigmoid | нужен **`(m,)`** |
| несколько `p` в батче | **m объектов**, не softmax-классы |
| «умножаю в ML» | forward слоя → `@`; loss/нормализация → `*` |

### Мини-таблица форм

| Выражение | Результат |
|:---|:---|
| `(m, d) * (d,)` | `(m, d)` |
| `(m, d).sum(axis=1)` | `(m,)` |
| `(m, d) @ (d,)` | `(m,)` |
| `(m, d) @ (d, h)` | `(m, h)` |
