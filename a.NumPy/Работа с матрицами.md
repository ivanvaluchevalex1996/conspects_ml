<a id="одна-фраза"></a>
## 📌 Одна фраза

> `A @ B` — матричное умножение: **внутренние** размеры должны совпасть, результат — внешние.

---

<a id="правило-для-a-b"></a>
## 🔷 Правило для A @ B

```
A: (строки_A, столбцы_A)
B: (строки_B, столбцы_B)
```

Можно умножить, если:

```
столбцы_A == строки_B
     ↑ «внутренние» размеры совпали
```

Результат:

```
(строки_A, столбцы_B)
```

Коротко:

```
(A, B) @ (B, C)  →  (A, C)
```

---

<a id="все-основные-случаи"></a>
## 🔷 Все основные случаи `@`

<a id="1-вектор-вектор-скаляр"></a>
### 1. Вектор @ Вектор → скаляр

```
(n,) @ (n,)  →  ()
```

```python
np.array([1, 2, 3]) @ np.array([4, 5, 6])  # = 32
```

Оба одномерные. Результат — одно число (скалярное произведение / линейное ядро).

<a id="2-матрица-вектор-вектор"></a>
### 2. Матрица @ Вектор → вектор

```
(m, n) @ (n,)  →  (m,)
```

```python
X = np.array([[1, 2],
              [3, 4],
              [5, 6]])   # (3, 2)

w = np.array([1, 0.5])   # (2,)

X @ w   # (3,) → [2, 5, 8]
```

Вектор справа «прилипает» к столбцам. В ML: `X @ w` = предсказания.

<a id="3-вектор-матрица-вектор"></a>
### 3. Вектор @ Матрица → вектор

```
(m,) @ (m, n)  →  (n,)
```

```python
v = np.array([1, 2])         # (2,)

B = np.array([[1, 2, 3],
              [4, 5, 6]])    # (2, 3)

v @ B   # (3,) → [9, 12, 15]
```

Вектор слева «прилипает» к строкам.

<a id="4-матрица-матрица-матрица"></a>
### 4. Матрица @ Матрица → матрица

```
(m, n) @ (n, p)  →  (m, p)
```

```python
A = np.array([[1, 2, 3],
              [4, 5, 6]])   # (2, 3)

B = np.array([[1, 0],
              [0, 1],
              [1, 1]])      # (3, 2)

A @ B   # (2, 2)
```

---

<a id="мнемоника-схема-сэндвич"></a>
## 🧠 Мнемоника: схема «сэндвич»

```
     ┌──── внутренние ────┐
     ↓                    ↓
   (m, n)    @    (n, p)   →   (m, p)
    ↑                    ↑
     └──── внешние ──────┘
```

- **Внутренние** (`n` и `n`) — должны совпасть 
- **Внешние** (`m` и `p`) — становятся формой результата 

**Фраза:** «Средние совпали — крайние в результат»

Почему так: умножение = скалярные произведения «строка слева × столбец справа», поэтому у строки и столбца должно быть одинаковое число элементов.

---

<a id="что-не-нужно"></a>
## 🔷 Что не нужно

| Мысль | Верно? |
|:---|:---|
| У обеих матриц одинаковая форма | ❌ для `@` не подходит |
| Первые числа совпали: `(3073, 10) @ (3073, 10)` | ❌ |
| Последние числа совпали: `(9000, 3073) @ (10, 3073)` | ❌ (`3073 ≠ 10`) |

Сравнивают **не** «оба shape одинаковые» и **не** первые/последние числа подряд — только **внутреннюю пару**.

---

<a id="пример"></a>
## 🔷 Пример

```
X: (9000, 3073)     9000 строк, 3073 столбца
W: (3073, 10)       3073 строки, 10 столбцов

3073 == 3073  ✅
X @ W → (9000, 10)
```

- 9000 и 3073 сравнивать **не надо**
- сравниваем столбцы X с строками W

Мини-пример:

```
(2, 3) @ (3, 10) = (2, 10)

2 и 3 — не сравниваем
3 и 3 — сравниваем ✅
```

---

<a id="пример-с-числами"></a>
## 🔷 Пример с числами

```
X: (2, 3)     2 строки, 3 столбца
W: (3, 2)     3 строки, 2 столбца

predictions = X @ W  →  (2, 2)
```

```python
# например:
[[ 1, -1],
 [ 0,  3]]
```

2 строки × 2 столбца — форма сходится.

---

<a id="правило-размеров-запомни-одно"></a>
## 🔷 Правило размеров (запомни одно)

```
X:           (batch, features)
W:           (features, classes)
                 @
predictions: (batch, classes)
```

| X | W | результат |
|:---|:---|:---|
| `(2, 3)` | `(3, 2)` | `(2, 2)` |
| `(1, 3073)` | `(3073, 10)` | `(1, 10)` |
| `(300, 3073)` | `(3073, 10)` | `(300, 10)` |
| `(9000, 3073)` | `(3073, 10)` | `(9000, 10)` |

<a id="vs"></a>
## 🔷 @ vs *

| оператор | что делает |
|:---|:---|
| `@` / `np.matmul` | матричное умножение |
| `*` | поэлементное (формы должны стыковаться / broadcasting) |

```python
A * B   # каждый элемент с каждым
A @ B   # строки × столбцы по правилу матриц
```

<a id="коротко-запомнить"></a>
## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `@`: внутренние размеры совпали → `(A, B) @ (B, C) = (A, C)` |
| 2 | 4 случая: `(n,)@(n,)→скаляр`, `(m,n)@(n,)→(m,)`, `(m,)@(m,n)→(n,)`, `(m,n)@(n,p)→(m,p)` |
| 3 | Одинаковый shape **не** значит, что `@` сработает |
| 4 | Шаблон: `(batch, features) @ (features, classes) = (batch, classes)` |
| 5 | `*` — поэлементно, `@` — матрично |
| 6 | Мнемоника: «средние совпали — крайние в результат» |
