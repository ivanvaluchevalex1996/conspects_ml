## 📌 Одна фраза

> Математические функции NumPy (**ufunc**) считаются **поэлементно** сразу над всем массивом: арифметика, корни/степени, `exp`/`log`, округления, `abs`/`sign`, `clip`, `diff`.

---

## 🔷 Арифметика — поэлементно

```python
a = np.array([1, 2, 3])
b = np.array([10, 20, 30])

a + b     # [11 22 33]
a - b     # [ -9 -18 -27]
a * b     # [10 40 90]
b / a     # [10. 10. 10.]
b // a    # [10 10 10]     — целочисленное деление
b % a     # [0 0 0]        — остаток
a ** 2    # [1 4 9]        — степень
```

> 💡 В **этом** файле `*` = ufunc по массиву. Когда `*` vs `@`, размеры, логиты — один конспект [`11.умножение — star, at, dot`](11.%D1%83%D0%BC%D0%BD%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5%20%E2%80%94%20star%2C%20at%2C%20dot.md).

## 🔷 Корни и степени

```python
np.sqrt([1, 4, 9])       # [1. 2. 3.]
np.square([2, 3])        # [4 9]
np.power([2, 3], 3)      # [8 27]
```

## 🔷 Экспонента и логарифмы

```python
np.exp([0, 1])           # [1.         2.71828183]   — ELU (#97), Swish (#102): см. d.4.1 §9.4 (таблица)
np.log([1, np.e])        # [0. 1.]       — натуральный
np.log2([1, 8])          # [0. 3.]
np.log10([1, 100])       # [0. 2.]
```

> ⚠️ `np.log(0)` → `-inf`, `np.log(-1)` → `nan` (с предупреждением).

**`log(1 + u)` без потери точности:** в **softplus (#99)** — `math.log1p(u)` / `np.log1p(u)`. Стабильная формула в [`d.4.1` §9.4](../d.%D0%9C%D0%B0%D1%88%D0%B8%D0%BD%D0%BD%D0%BE%D0%B5%20%D0%BE%D0%B1%D1%83%D1%87%D0%B5%D0%BD%D0%B8%D0%B5/d.4%20Deep%20Learning/d.4.1%20%D0%9F%D0%BE%D0%BB%D0%BD%D0%BE%D1%81%D0%B2%D1%8F%D0%B7%D0%BD%D1%8B%D0%B5%20%D0%BD%D0%B5%D0%B9%D1%80%D0%BE%D0%BD%D0%BD%D1%8B%D0%B5%20%D1%81%D0%B5%D1%82%D0%B8.md).

## 🔷 Округления

```python
a = np.array([1.4, 1.6, 2.5, -1.2])

np.round(a)      # [ 1.  2.  2. -1.]   — «банковское» (0.5 → ближайшее чётное!)
np.floor(a)      # [ 1.  1.  2. -2.]
np.ceil(a)       # [ 2.  2.  3. -1.]
np.trunc(a)      # [ 1.  1.  2. -1.]
np.round(a, 1)   # округлить до одного знака
```

> ⚠️ `np.round(2.5)` → `2.0`, а не `3` (округление к **чётному**). И не путать с `astype(int)` — тот просто **обрезает** (см. `0.Создание массивов.md`).

## 🔷 `abs` и `sign`

```python
np.abs([-3, 3, -0.5])    # [3.  3.  0.5]
np.sign([-5, 0, 5])      # [-1  0  1]
```

## 🔷 `clip` — загнать в диапазон

**Связь с DL:** обрезка в `[0, 1]` после линейного куска — идея **hard sigmoid** (Deep-ML [#96](https://www.deep-ml.com/problems/96), `hard_sigmoid` в [`13_deep_ml_deep_learning.py`](../../%D1%83%D1%87%D0%B5%D0%B1%D0%B0%20%D0%BC%D0%BB/python_base/13_deep_ml_deep_learning.py); теория — [`d.4.1` §9.2](../d.%D0%9C%D0%B0%D1%88%D0%B8%D0%BD%D0%BD%D0%BE%D0%B5%20%D0%BE%D0%B1%D1%83%D1%87%D0%B5%D0%BD%D0%B8%D0%B5/d.4%20Deep%20Learning/d.4.1%20%D0%9F%D0%BE%D0%BB%D0%BD%D0%BE%D1%81%D0%B2%D1%8F%D0%B7%D0%BD%D1%8B%D0%B5%20%D0%BD%D0%B5%D0%B9%D1%80%D0%BE%D0%BD%D0%BD%D1%8B%D0%B5%20%D1%81%D0%B5%D1%82%D0%B8.md#92-sigmoid--%D0%B0%D0%BA%D1%82%D0%B8%D0%B2%D0%B0%D1%86%D0%B8%D1%8F-%D0%B2%D1%8B%D1%85%D0%BE%D0%B4%D0%BD%D0%BE%D0%B3%D0%BE-%D1%81%D0%BB%D0%BE%D1%8F-%D0%B1%D0%B8%D0%BD%D0%B0%D1%80%D0%BD%D0%B0%D1%8F-%D0%B7%D0%B0%D0%B4%D0%B0%D1%87%D0%B0)).

```python
np.clip([1, 5, 10, -3], 2, 8)   # [2 5 8 2]

a = np.array([1, 5, 10, -3])
a.clip(2, 8)                    # то же — методом
```

## 🔷 `diff` — разности соседей


## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | ufunc работают **поэлементно** над всем массивом (без циклов) |
| 2 | `*` поэлементно, `@` — матрично |
| 3 | `sqrt`/`square`/`power`; `exp`/`log`/`log2`/`log10` |
| 4 | `np.round` — «банковское» (0.5 → чётное); `floor`/`ceil`/`trunc` |
| 5 | `np.abs`/`np.sign`; `clip(lo, hi)` — ограничить диапазон |
| 6 | `np.diff` — разности соседних элементов |
