
# 🔀 `split` и `join`: Python vs JavaScript — шпаргалка, чтобы не путаться

> Ты знал JS первым — поэтому запоминай **через сравнение с JS**.
>
> Главный вывод: `split` и `join` — это противоположные операции. В обоих языках они называются почти одинаково, но есть нюансы.

---

## 🧠 Главная идея (запомни это)

```
строка  --split-->  список/массив
список/массив  --join-->  строка
```

- `split` — «разрезает» строку на части. Кто вызывает? **Строка**. Результат — **массив/список**.
- `join` — «склеивает» части в строку. Аргумент — **массив/список**. Результат — строка.

⚠️ **Ключевое правило, чтобы не путаться:**

| Операция | Кто вызывает метод | Что передаём аргументом | Что получаем |
|----|----|----|----|
| `split` | **строку** | разделитель (строку) | массив/список |
| `join` | **строку-разделитель** | массив/список | строку |

👉 В **обоих** языках `join` — это метод **строки**, а не массива. Это самая частая путаница.

---

## 📊 Таблица соответствий

| Что нужно | JavaScript | Python |
|----|----|----|
| Разбить строку по символу | `"a,b,c".split(",")` | `"a,b,c".split(",")` |
| Разбить по пробелам (любым) | `"a b  c".split(/\s+/)` *или* `"a b c".split(" ")` | `"a b  c".split()` ← **без аргумента!** |
| Склеить массив в строку | `["a","b","c"].join(",")` | `",".join(["a","b","c"])` |
| Склеить без разделителя | `["a","b"].join("")` | `"".join(["a","b"])` |
| Объединить массив символов | `[...word].join("")` | `"".join(word)` |

## 1️⃣ `split` — строка → массив/список

### JavaScript

```js
"a,b,c".split(",");        // ["a", "b", "c"]
"hello".split("");         // ["h", "e", "l", "l", "o"]
"a b  c".split(" ");       // ["a", "b", "", "c"]   (пустой элемент!)
"a b  c".split(/\s+/);     // ["a", "b", "c"]       (регулярка — чистит пробелы)
"a-b-c".split("-", 2);     // ["a", "b"]            (лимит: только 2 части)
```

### Python

```python
"a,b,c".split(",")         # ['a', 'b', 'c']
list("hello")              # ['h', 'e', 'l', 'l', 'o']  (split("") НЕ работает!)
"a b  c".split()           # ['a', 'b', 'c']   ← без аргумента режет по любым пробелам/табам/переносам
"a b  c".split(" ")        # ['a', 'b', '', 'c']  ← как в JS, оставляет пустые
"a-b-c".split("-", 2)      # ['a', 'b', 'c']   ← ВАЖНО: maxsplit разбиений, а НЕ количество частей
```

### 🔥 Различия, из-за которых путаются

| Момент | JavaScript | Python |
|----|----|----|
| `split("")` | работает → массив символов | ❌ `ValueError: empty separator` — используй `list(s)` |
| `split()` без аргумента | равен `split(" ")` (по литеральному пробелу) | режет по **любым** пробельным символам и **убирает пустые** |
| Второй аргумент | **limit** = максимум **частей** | **maxsplit** = число **разрезов** |
| `"a-b-c".split("-", 2)` | `["a","b-c"]` (2 части) | `['a','b','c']` (2 разреза = 3 части) |
| Регулярки | ✅ поддерживаются напрямую | ❌ нужен модуль `re`: `re.split(r"\s+", s)` |

> 💡 **Python-версия split с регуляркой:**
>
> ```python
> import re
> re.split(r"\s+", "a   b c")   # ['a', 'b', 'c']
> ```

## 2️⃣ `join` — массив/список → строка

### JavaScript (`Array.prototype.join`)

```js
["a", "b", "c"].join("-");   // "a-b-c"
["a", "b", "c"].join("");    // "abc"
[1, 2, 3].join(" / ");       // "1 / 2 / 3"   (числа автоматически → строка)
[].join(",");                // ""
```

### Python (`str.join` — метод СТРОКИ, не списка!)

```python
"-".join(["a", "b", "c"])    # 'a-b-c'
"".join(["a", "b", "c"])     # 'abc'
" / ".join(["1", "2", "3"])  # '1 / 2 / 3'   (здесь всё строки)
"".join(["h", "e", "l", "l", "o"])  # 'hello'
" ".join([1, 2, 3])          # ❌ TypeError! нужны строки
" ".join(map(str, [1, 2, 3]))       # '1 2 3'  ✅  (или str(i) for i in ...)
```

### 🔥 Здесь ГЛАВНОЕ различие в синтаксисе

```js
// JS: разделитель — ЭТО АРГУМЕНТ, массив — ЭТО ВЫЗЫВАЮЩИЙ
["a","b"].join("-")
// ↑ массив.join(разделитель)
```

```python
# Python: разделитель — ЭТО ВЫЗЫВАЮЩИЙ, список — ЭТО АРГУМЕНТ
"-".join(["a","b"])
# ↑ разделитель.join(список)
```

> 🧠 **Мнемоника:**
>
> - **JS** — «я массив, склей себя символом-аргументом» → `arr.join(sep)`
> - **Python** — «я строка-разделитель, вклей в себя вот этот список» → `sep.join(list)`

---

## 3️⃣ Только в Python: `join` требует строки

`str.join` в Python **не приводит числа автоматически**. Это защита от ошибок.

```python
# ❌ упадёт
",".join([1, 2, 3])            # TypeError: sequence item 0: expected str instance, int found

# ✅ варианты
",".join(str(x) for x in [1, 2, 3])   # '1,2,3'
",".join(map(str, [1, 2, 3]))         # '1,2,3'
```

А в JS `join` сам вызывает `toString`:

```js
[1, 2, 3].join(",")   // "1,2,3"  ✅  (без ошибок)
```

## 4️⃣ Аналогии «делаю то же самое»

### Перевернуть строку

```js
"hello".split("").reverse().join("")   // "olleh"
```

```python
"hello"[::-1]                          # 'olleh'  (срезом — проще!)
"".join(reversed("hello"))             # 'olleh'  (через join, как в JS)
```

### Разбить на слова

```js
"hello world  foo".split(/\s+/);       // ["hello","world","foo"]
```

```python
"hello world  foo".split()             # ['hello','world','foo']
```

### Собрать CSV из массива

```js
[1,2,3].map(String).join(", ");        // "1, 2, 3"
```

```python
", ".join(str(x) for x in [1,2,3])     # '1, 2, 3'
```

### Получить список символов строки

```js
"abc".split("");        // ["a","b","c"]
```

```python
list("abc")             # ['a','b','c']   (split("") нельзя!)
```

## ✅ Итоговая таблица «чтобы не путаться»

| Признак | JavaScript | Python |
|----|----|----|
| `split` вызывается на | строке | строке |
| `split` возвращает | массив | список |
| `split("")` | ✅ массив символов | ❌ ошибка → `list(s)` |
| `split()` без аргум. | = `split(" ")` (только пробел) | режет по всем пробелам, без пустых |
| Второй аргумент `split` | limit = кол-во **частей** | maxsplit = кол-во **разрезов** |
| `split` с regex | ✅ нативно | ❌ через `re.split` |
| `join` — чей метод | **массива** | **строки** |
| Порядок вызова `join` | `arr.join(sep)` | `sep.join(list)` |
| `join` и числа | авто-`toString` ✅ | ❌ нужен `str()` / `map(str, ...)` |
| Пустой разделитель | `join("")` | `"".join(...)` |

---

## 🎯 Три предложения для памяти

1. `split` режет строку → даёт массив, вызывается на строке — в обоих языках одинаково.
2. `join` склеивает массив → даёт строку, но в JS вызывается на **массиве** (`arr.join(sep)`), а в Python — на **строке-разделителе** (`sep.join(list)`).
3. **В Python** `join` не прощает числа — оборачивай в `str()`/`map(str, ...)`; в JS он сам всё приведёт к строке.
