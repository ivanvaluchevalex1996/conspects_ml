# Математические обозначения — справочник по формулам и знакам

Этот конспект — не учебник, а **справочник**. Он нужен для одного: когда в лекции, книге или в чужом выводе встретился непонятный знак — открыть и подсмотреть.

Главная мысль такая: почти каждый «страшный» символ — это просто короткое сокращение для того, что ты уже умеешь делать руками. $\sum$ — «сложи много штук», $\lim$ — «посмотри, куда идёт», $f'$ — «насколько быстро меняется». Никакой мистики.

---

## Как пользоваться справочником

| Если непонятно | Ищи раздел |
|---|---|
| Греческая буква: $\alpha$, $\theta$, $\lambda$ | Греческие буквы |
| Что-то складывают: $\sum$ | Сумма и произведение |
| «Стремится к»: $\lim$, $x \to a$ | Предел |
| Штрих, $\dfrac{dy}{dx}$, $\nabla$ | Производные |
| Значок $\int$ | Интеграл |
| Логарифм, $\ln$, $e^x$, модуль | Логарифмы, экспонента, модуль |
| «Для любого», «существует», $\in$ | Логические символы, Множества |
| $\mathbb{R}$, $\mathbb{N}$ | Числовые множества |
| Жирные буквы, $\mathbf{x}^T$, $\det$, $\hat{y}$ | Векторы и матрицы |
| $P(A)$, $\mathbb{E}[X]$, $\operatorname{Var}$ | Вероятность и статистика |
| $\arg\max$, $\min$ | argmax и argmin |
| Стрелки разного вида | Стрелки |
| `\begin{cases}`, `\dfrac`, `\boxed` | Служебные команды LaTeX |
| Символ без обратного слэша: →, ∞, ∑, ŷ | Символы в Unicode-виде |

## Базовые знаки

| Знак | Как читается | Что значит | Пример |
|---|---|---|---|
| $+$ | плюс | сложение | $2 + 3 = 5$ |
| $-$ | минус | вычитание | $5 - 3 = 2$ |
| $\times$ | умножить | умножение чисел | $4 \times 3 = 12$ |
| $\cdot$ | умножить | то же, но чаще рядом с буквами | $a \cdot b$ |
| (ничего) | — | буквы рядом тоже означают умножение | $2x = 2 \cdot x$ |
| $\div$ | разделить | деление | $6 \div 3 = 2$ |
| $\dfrac{a}{b}$ | «а на бэ» | дробь = деление $a$ на $b$ | $\dfrac{6}{3} = 2$ |
| $=$ | равно | слева и справа одно и то же | $2 + 2 = 4$ |
| $\neq$ | не равно | значения разные | $3 \neq 4$ |
| $\approx$ | приблизительно равно | почти равно, но не точно | $\pi \approx 3{,}14$ |
| $\equiv$ | тождественно равно | верно при любых значениях | $\sin^2 x + \cos^2 x \equiv 1$ |
| $\pm$ | плюс-минус | два варианта: с плюсом и с минусом | $x = \pm 3$ → $3$ или $-3$ |
| $<$ | меньше | | $2 < 5$ |
| $>$ | больше | | $5 > 2$ |
| $\leq$, $\le$ | меньше или равно | две записи — это одно и то же | $x \leq 10$ |
| $\geq$, $\ge$ | больше или равно | две записи — это одно и то же | $x \geq 0$ |
| $\gg$ | «много больше» | настолько больше, что разницей можно пренебречь | $10^6 \gg 10$ |
| $\lvert x \rvert$, $\vert x \vert$ | модуль икс | расстояние от нуля, всегда без минуса | $\lvert -5 \rvert = 5$ |
| $\infty$ | бесконечность | не число, а «растёт без границы» | см. раздел «Предел» |

## Дроби, степени, корни

| Запись | Как читается | Смысл |
|---|---|---|
| $\dfrac{a}{b}$ | «а на бэ» | $a$ делить на $b$ |
| $x^2$ | икс в квадрате | $x \cdot x$ |
| $x^3$ | икс в кубе | $x \cdot x \cdot x$ |
| $x^n$ | икс в степени $n$ | $n$ штук иксов, перемноженных между собой |
| $x^{-1}$ | икс в минус первой | $\dfrac{1}{x}$ |
| $x^{1/2} = \sqrt{x}$ | корень из икс | число, которое в квадрате даёт $x$ |
| $\sqrt[3]{x}$ | кубический корень | число, которое в кубе даёт $x$ |
| $x^{a+b} = x^a \cdot x^b$ | — | правило степеней: степени складываются |
| $(x^a)^b = x^{ab}$ | — | степень в степени: показатели перемножаются |

Сложные дроби (когда дробь стоит в числителе) разобраны отдельно в конспекте `Сложные дроби (дробь в числителе)`.

## Логарифмы, экспонента, модуль

| Запись | Чтение | Смысл |
|---|---|---|
| $\log x$ | «логарифм икс» | в какую степень возвести основание, чтобы получить $x$ |
| $\ln x$ | «натуральный логарифм» | логарифм по основанию $e \approx 2{,}718$ |
| $\lg x$ | «десятичный логарифм» | логарифм по основанию 10 |
| $\log_2 x$ | «логарифм по основанию 2» | основание указано снизу |
| $\exp(x)$ | «экспонента» | то же самое, что $e^x$ |
| $e$ | «е» | число Эйлера, $\approx 2{,}71828$ |
| $\lvert x \rvert$ | «модуль икс» | расстояние до нуля: минус отбрасывается |
| $\lVert \mathbf{x} \rVert$ | «норма икс» | длина вектора (не путать с модулем числа) |

Правила, которые нужны на каждом шагу:

$$
\ln(ab) = \ln a + \ln b, \qquad \ln\frac{a}{b} = \ln a - \ln b, \qquad \ln(a^k) = k \ln a
$$

> **Важно:** $\log$ без указания основания — это «логарифм вообще», и в ML под ним почти всегда имеют в виду **натуральный** ($\ln$). Поэтому $\log$ и $\ln$ там часто пишут как одно и то же.

Подробнее — в конспекте `Логарифмы`.

## Индексы: нижний и верхний

Это самое частое место, где путаются. Разница простая: **снизу — номер, сверху — степень**.

| Запись | Где индекс | Что значит | Пример |
|---|---|---|---|
| $x^2$ | сверху | степень (умножение) | $3^2 = 9$ |
| $x_n$ | снизу | **номер** элемента, а не степень | $x_1, x_2, x_3$ — первый, второй, третий |
| $x_i$ | снизу | «икс с индексом $i$» — какой-то из элементов | $i$ пробегает 1, 2, 3, ... |
| $x^{(2)}$ | сверху, в скобках | тоже номер (скобки отличают от степени) | второй пример/набор |
| $a_{ij}$ | снизу, два индекса | элемент в строке $i$, столбце $j$ | матрица |
| $x_i^2$ | и снизу, и сверху | элемент номер $i$, возведённый в квадрат | $(x_i)^2$ |

> **Запомни:** маленький значок снизу — это почти всегда «номер», сверху — «степень». Если сверху стоит номер, его пишут в скобках: $x^{(2)}$.

## Греческие буквы

Греческими буквами обозначают **переменные и параметры** — просто чтобы обычных $a, b, c, x, y, z$ хватило всем. Сами буквы ровно ничего не значат, это всего лишь имена.

### Строчные (маленькие)

| Буква | Имя | Где обычно встречается |
|---|---|---|
| $\alpha$ | альфа | скорость обучения (learning rate), угол |
| $\beta$ | бета | коэффициенты, угол |
| $\gamma$ | гамма | коэффициент дисконтирования, множитель |
| $\delta$ | дельта | маленькое изменение величины |
| $\varepsilon$, $\epsilon$ | эпсилон | очень маленькое число (точность, $\varepsilon \to 0$) |
| $\zeta$ | дзета | встречается редко, нормировка |
| $\eta$ | эта | **скорость обучения** (тогда $\alpha$ остаётся для другого), КПД |
| $\theta$ | тета | параметры модели (веса) |
| $\kappa$ | каппа | константа, число групп |
| $\lambda$ | лямбда | коэффициент регуляризации, собственное значение |
| $\mu$ | мю | среднее значение |
| $\nu$ | ню | число степеней свободы |
| $\xi$ | кси | погрешность, случайная величина |
| $\pi$ | пи | число $3{,}14159...$; ещё «вероятность» |
| $\rho$ | ро | плотность, коэффициент корреляции |
| $\sigma$ | сигма | стандартное отклонение |
| $\tau$ | тау | шаг, время |
| $\varphi$, $\phi$ | фи | функция-признак |
| $\chi$ | хи | критерий хи-квадрат |
| $\psi$ | пси | функция, волновая функция |
| $\omega$ | омега | частота, вес |

### Заглавные (большие)

| Буква | Имя | Где встречается |
|---|---|---|
| $\Delta$ | дельта (большая) | **изменение** величины: $\Delta x = x_2 - x_1$ |
| $\Sigma$ | сигма (большая) | знак суммы, см. раздел «Сумма и произведение» |
| $\Pi$ | пи (большая) | знак произведения |
| $\Phi$ | фи (большая) | функция распределения |
| $\Omega$ | омега (большая) | «порядок роста», сложность алгоритма $O(...)$ |
| $\Theta$ | тета (большая) | «растёт так же быстро, как» |

> **Не путай:** $\delta$ (маленькая) — «маленькое изменение», а $\Delta$ (большая) — «изменение вообще». И $\Sigma$ (большая сигма) — это знак суммы, а не буква-переменная.

## Как записывают функции

| Запись | Чтение | Смысл |
|---|---|---|
| $f(x)$ | «эф от икс» | функция $f$, применённая к $x$: подставили $x$ — получили результат |
| $f(x, y)$ | «эф от икс и игрек» | функция двух аргументов |
| $f: X \to Y$ | «эф из икс в игрек» | берёт элементы из $X$ и выдаёт элементы из $Y$ |
| $f(x) = 2x + 1$ | — | правило: возьми $x$, умножь на 2, прибавь 1 |
| $y = f(x)$ | — | $y$ — результат, $x$ — вход |
| $f^{-1}$ | «эф обратная» | обратная функция: отменяет действие $f$ |

> **Осторожно со скобками:** в $f(x)$ скобки — это «подставили аргумент», а не умножение. Умножение записывают без скобок или через точку: $f \cdot x$.

## Сумма и произведение

### $\sum$ — «сложить много штук»

$$
\sum_{i=1}^{n} x_i = x_1 + x_2 + x_3 + \dots + x_n
$$

Читаем запись по частям:

| Часть | Что это | По-русски |
|---|---|---|
| $\sum$ | большая сигма | «сумма» |
| $i = 1$ (снизу) | откуда начинаем | «начиная с $i = 1$» |
| $n$ (сверху) | до чего идём | «до $i = n$» |
| $x_i$ (справа) | что складываем | «складываем все $x_i$» |

**Примеры:**

$$
\sum_{i=1}^{4} i = 1 + 2 + 3 + 4 = 10
$$

$$
\sum_{i=1}^{3} x_i = x_1 + x_2 + x_3
$$

Значок $\sum$ без нижнего и верхнего предела — это просто «сумма по смыслу контекста».

### $\prod$ — «перемножить много штук»

$$
\prod_{i=1}^{n} x_i = x_1 \cdot x_2 \cdot x_3 \cdots x_n
$$

**Пример:** $\displaystyle\prod_{i=1}^{4} i = 1 \cdot 2 \cdot 3 \cdot 4 = 24$

### Факториал $n!$

$$
n! = 1 \cdot 2 \cdot 3 \cdots n
$$

$3! = 6$, $5! = 120$. По определению $0! = 1$.

> **Разница на пальцах:** $\sum$ — складываем, $\prod$ — умножаем, $n!$ — умножаем все числа от 1 до $n$.

## Предел: $\lim$

$\lim$ отвечает на вопрос: **«к чему идёт выражение, когда переменная подходит всё ближе к какой-то точке?»** Это не «подставить число», а «посмотреть направление».

### Основной вид

$$
\lim_{x \to a} f(x) = L
$$

Читается: «предел $f(x)$ при $x$, стремящемся к $a$, равен $L$».

| Часть | Смысл |
|---|---|
| $\lim$ | «предел» |
| $x \to a$ | $x$ **стремится** к $a$: подходит сколь угодно близко, но не обязан равняться $a$ |
| $f(x)$ | выражение, за которым следим |
| $= L$ | число, к которому всё подходит |

### Стремление к бесконечности

$$
\lim_{x \to \infty} \frac{1}{x} = 0
$$

«Чем больше $x$, тем ближе $\dfrac{1}{x}$ к нулю».

### Виды пределов

| Запись | Чтение | Смысл |
|---|---|---|
| $\lim_{x \to a}$ | предел при $x \to a$ | обычный предел |
| $\lim_{x \to a^+}$ | предел справа | $x$ подходит к $a$ только с большей стороны |
| $\lim_{x \to a^-}$ | предел слева | $x$ подходит к $a$ только с меньшей стороны |
| $\lim_{x \to \infty}$ | на бесконечности | $x$ растёт без границы |
| $\lim_{n \to \infty}$ | по целому $n$ | то же самое, если переменная целая |

> **Важно:** предел может существовать, даже если в самой точке функция не определена. Например, $\dfrac{1}{x}$ в нуле не определена, но её предел при $x \to \infty$ равен 0.

Подробнее — в конспектах `Предел, конспект` и `1.Предел, конспект`.

## Производные

Производная — это «скорость изменения»: насколько быстро меняется результат, когда чуть-чуть шевелим вход.

| Запись | Чтение | Смысл |
|---|---|---|
| $f'(x)$ | «эф штрих от икс» | производная функции $f$ |
| $\dfrac{dy}{dx}$ | «дэ игрек по дэ икс» | то же самое, что $f'(x)$: как $y$ меняется вместе с $x$ |
| $f''(x)$ | «эф два штриха» | вторая производная (производная от производной) |
| $\dfrac{d^2y}{dx^2}$ | «дэ два игрек по дэ икс квадрат» | вторая производная |
| $\dfrac{d}{dx}$ | «дэ по дэ икс» | **оператор**: «возьми производную по $x$» |
| $\dot{x}$ | «икс с точкой» | производная по времени (физика) |

### Частные производные: $\partial$

Когда переменных несколько, значок $\partial$ («дэ», «партиал») говорит: берём производную **только по одной** переменной, остальные считаем замороженными.

| Запись | Смысл |
|---|---|
| $\dfrac{\partial f}{\partial x}$ | как $f$ меняется, если шевелить только $x$ |
| $\dfrac{\partial f}{\partial y}$ | как $f$ меняется, если шевелить только $y$ |
| $f_x$ | короткая запись для $\dfrac{\partial f}{\partial x}$ |

### Градиент: $\nabla$

$$
\nabla f = \left( \frac{\partial f}{\partial x}, \frac{\partial f}{\partial y} \right)
$$

$\nabla$ («набла») — это **вектор из всех частных производных сразу**. Он показывает направление самого быстрого роста функции, и именно на нём держится градиентный спуск.

> **Разница одним предложением:** $\dfrac{dy}{dx}$ — одна переменная; $\dfrac{\partial f}{\partial x}$ — переменных много, но берём по одной; $\nabla f$ — все частные производные собраны в вектор.

Подробнее — в конспектах `Производная`, `Расчет производной`, `Шаг в градиентном спуске`.

## Интеграл

Интеграл — операция, обратная производной (и одновременно накопление площади). Здесь важно узнать обозначение, а не научиться считать.

| Запись | Чтение | Смысл |
|---|---|---|
| $\int f(x)\,dx$ | «интеграл эф от икс дэ икс» | неопределённый интеграл: семейство первообразных |
| $\int_a^b f(x)\,dx$ | «интеграл от $a$ до $b$» | определённый интеграл — одно число (площадь под графиком) |
| $dx$ | «дэ икс» | по какой переменной интегрируем |
| $\iint$ | двойной интеграл | по площади (двум переменным) |
| $\oint$ | интеграл по контуру | по замкнутой линии |

$$
\int_a^b f(x)\,dx = F(b) - F(a)
$$

где $F$ — первообразная, то есть $F'(x) = f(x)$.

> **Связь:** производная и интеграл — противоположные операции. Производная «разбирает» на скорость изменения, интеграл «собирает» изменение обратно.

## Логические символы

Их много в определениях и теоремах — там, где пишут «для любого» и «существует».

| Знак | Чтение | Смысл |
|---|---|---|
| $\forall$ | «для любого» | утверждение верно для всех элементов |
| $\exists$ | «существует» | найдётся хотя бы один |
| $\exists!$ | «существует единственный» | ровно один |
| $\neg$ | «не» | отрицание |
| $\wedge$ | «и» | оба утверждения верны |
| $\vee$ | «или» | верно хотя бы одно |
| $\Rightarrow$ | «следует» | если первое, то второе |
| $\Leftrightarrow$ | «равносильно» | одно верно тогда и только тогда, когда второе |

**Пример:** $\forall x \in \mathbb{R} \; \exists y \in \mathbb{R}: x + y = 0$ — «для любого действительного $x$ найдётся такой $y$, что $x + y = 0$».

## Множества

| Знак | Чтение | Смысл |
|---|---|---|
| $\{\, \}$ | множество | перечисление элементов или правило |
| $\in$ | «принадлежит» | элемент лежит в множестве: $3 \in \mathbb{R}$ |
| $\notin$ | «не принадлежит» | элемента в множестве нет |
| $\subseteq$ | «подмножество» | все элементы одного входят в другое |
| $\subset$ | строгое подмножество | входит, но множества не совпадают |
| $\cup$ | объединение | «всё из первого **или** второго» |
| $\cap$ | пересечение | «то, что есть **и** там, и там» |
| $\varnothing$ | пустое множество | элементов нет |
| $\setminus$ | разность | «из первого выбросить элементы второго» |
| $A \mid b$ | «такие, что» | $x \mid x > 0$ — «иксы, такие что $x > 0$» |

**Пример:** $x \in \mathbb{R}$ — «$x$ — действительное число»; $A \cup B$ — «всё, что лежит в $A$ или в $B$».

## Стрелки

Одни и те же стрелки в разных местах значат разное, поэтому их стоит смотреть по контексту.

| Стрелка | Чтение | Где встречается |
|---|---|---|
| $\to$ | «стремится к» | в пределе: $x \to 0$ |
| $\to$ | «отображает в» | в функции: $f: X \to Y$ |
| $\Rightarrow$ | «следует» | в логике: $A \Rightarrow B$ |
| $\Leftarrow$ | «из этого следует» | обратное следование |
| $\Leftrightarrow$ | «равносильно» | верно в обе стороны |
| $\mapsto$ | «переходит в» | что именно делает функция: $x \mapsto x^2$ |
| $\longrightarrow$, $\Longrightarrow$ | «отсюда следует...» (длинная) | длинная стрелка для длинных выводов, смысл тот же, что у $\to$ и $\Rightarrow$ |
| $\uparrow$ / $\downarrow$ | растёт / падает | поведение функции |

## Векторы и матрицы

В формулах векторы и матрицы часто выделяют жирным шрифтом или стрелкой.

| Запись | Чтение | Смысл |
|---|---|---|
| $\mathbf{x}$, $\vec{x}$ | «вектор икс» | вектор (набор чисел) |
| $x_i$ | элемент вектора | $i$-е число внутри вектора |
| $\mathbf{x}^T$ | «икс транспонированный» | вектор-столбец ↔ вектор-строка |
| $\mathbf{A}^{-1}$ | «А обратная» | матрица, которая отменяет действие $\mathbf{A}$ |
| $\lVert \mathbf{x} \rVert$ | «норма икс» | длина вектора |
| $\langle \mathbf{x}, \mathbf{y} \rangle$ | «скалярное произведение» | одно число из двух векторов |
| $\mathbf{x} \cdot \mathbf{y}$ | скалярное | то же самое |
| $\mathbf{A}\mathbf{x}$ | умножение | матрица действует на вектор |
| $\mathbf{w}^\top$, $\mathbf{w}^T$ | «дубль-вэ транспонированный» | строка ↔ столбец; так записывают скалярное произведение |
| $a_{ij}$ | элемент матрицы | строка $i$, столбец $j$ |
| $\det A$ | «определитель A» | число, по которому видно, обратима ли матрица |
| $\operatorname{tr} A$ | «след A» | сумма элементов на главной диагонали |
| $\circ$ | «произведение Адамара» | поэлементное умножение: $\mathbf{x} \circ \mathbf{y}$ |
| $\ell_1$, $\ell_2$ | «нормы эль-один, эль-два» | способы мерить длину: сумма модулей / корень из суммы квадратов |
| $\hat{y}$ | «игрек с шапкой» | **предсказание** модели (сам $y$ — настоящее значение) |
| $\otimes$ | тензорное произведение | более сложная операция |

Подробнее — в конспектах `Скаляры, векторы, матрицы, тензоры — конспект`, `Матрицы`, `Скалярное произведение`.

## argmax и argmin

| Запись | Чтение | Смысл |
|---|---|---|
| $\max_x f(x)$ | максимум $f$ | **самое большое значение** функции |
| $\min_x f(x)$ | минимум $f$ | **самое маленькое значение** функции |
| $\arg\max_x f(x)$ | «argmax» | **значение $x$**, при котором $f$ максимальна |
| $\arg\min_x f(x)$ | «argmin» | **значение $x$**, при котором $f$ минимальна |

**Разница:** $\max$ отдаёт значение, $\arg\max$ — вход.

Пример: если $f(x) = -(x-3)^2$, то $\max f(x) = 0$, а $\arg\max f(x) = 3$.

## Как читать формулу вслух

Возьмём «страшную» на вид запись и разберём её по кускам:

$$
\lim_{x \to 0} \frac{\sin x}{x} = 1
$$

Читается так:

> «Предел, при $x$, стремящемся к нулю, дроби $\sin x$ на $x$, равен единице».

Теперь по частям:

| Кусок | Что это |
|---|---|
| $\lim_{x \to 0}$ | предел, когда $x$ подходит к 0 |
| $\dfrac{\sin x}{x}$ | выражение, за которым следим |
| $= 1$ | число, к которому оно стремится |

Смысл: саму дробь $\dfrac{\sin x}{x}$ в нуле не посчитать (получится $\dfrac{0}{0}$), но **рядом с нулём** её значение подходит к 1.

## Служебные команды LaTeX (оформление, а не смысл)

Эти команды не обозначают математику — они только оформляют запись. Увидел такую — не ищи в ней смысл, его там нет.

| Команда | Что делает |
|---|---|
| $\frac{a}{b}$, $\dfrac{a}{b}$, $\tfrac{a}{b}$ | дробь: обычная / крупная / маленькая в строке |
| $\text{слово}$, $\mathrm{слово}$ | текст внутри формулы, не курсив |
| $\left( \right)$ | скобки, которые сами подстраиваются под высоту содержимого |
| $\Big($ | принудительно большая скобка |
| $\quad$, $\qquad$ | пробелы внутри формулы (маленький и большой) |
| `\begin{cases} ... \end{cases}` | система уравнений под одной фигурной скобкой |
| `\begin{pmatrix} ... \end{pmatrix}` | матрица в круглых скобках |
| `\begin{bmatrix} ... \end{bmatrix}` | матрица в квадратных скобках |
| `\boxed{...}` | рамка вокруг ответа |
| `\underbrace{...}` | подпись снизу под выражением |
| $\ldots$, $\cdots$ | многоточие по строке: внизу и по центру |
| $\vdots$, $\ddots$ | вертикальное и диагональное многоточие (в матрицах) |

## Те же символы можно писать просто так (Unicode)

Знаки встречаются двумя способами: как LaTeX-команда (с обратным слэшем) и как **готовый символ**. Это одно и то же — просто разная запись одного знака.

| Символ | LaTeX | Как это |
|---|---|---|
| → | `\to` | стремится к / отображает |
| ← | `\leftarrow` | обратное следование |
| ↑ ↓ | `\uparrow`, `\downarrow` | растёт / падает |
| ⇒ | `\Rightarrow` | следует |
| ⇔ | `\Leftrightarrow` | равносильно |
| ≈ | `\approx` | приблизительно равно |
| ≠ | `\neq` | не равно |
| ≤ ≥ | `\leq`, `\geq` | сравнения |
| ± | `\pm` | плюс-минус |
| ⋅ · | `\cdot` | умножение точкой |
| × | `\times` | умножение крестиком |
| − | `-` | минус |
| ∞ | `\infty` | бесконечность |
| ∑ | `\sum` | сумма |
| √ | `\sqrt` | корень |
| ∈ ∉ | `\in`, `\notin` | принадлежит / не принадлежит |
| ∪ ∩ | `\cup`, `\cap` | объединение / пересечение |
| ⊂ | `\subset` | подмножество |
| ≡ | `\equiv` | тождественно равно |
| ⟨ ⟩ | `\langle`, `\rangle` | скалярное произведение |
| ∣ | `\mid`, `\vert` | «такие, что» / «при условии» |
| α β γ η θ λ σ τ | `\alpha` `\beta` `\gamma` `\eta` `\theta` `\lambda` `\sigma` `\tau` | греческие буквы |
| Σ Π Φ Ω | `\Sigma` `\Pi` `\Phi` `\Omega` | заглавные греческие буквы |
| ŷ | `\hat{y}` | предсказание модели |
| x² x³ | `x^2`, `x^3` | степени |
| x₀ x₁ x₂ | `x_0`, `x_1`, `x_2` | нижние индексы |
| ⁻¹ | `^{-1}` | минус первая степень |
| ⌊x⌋ ⌈x⌉ | `\lfloor`, `\rceil` | округление вниз / вверх |
| ° | — | градусы |
| ₽ | — | рубли |

> **Практический вывод:** если видишь в формуле готовый символ (→, ∞, ∑, ŷ) — это не «другая математика», а тот же знак, просто записанный иначе.
