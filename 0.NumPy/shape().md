## 📌 Одна фраза

> **shape** — размеры массива: «сколько строк, сколько столбцов, сколько осей» — без самих чисел внутри.

---

## 🔷 Что делает

У каждого numpy-массива есть атрибут `.shape` — **кортеж** длин по осям.

```python
a = np.array([[1, 2, 3],
              [4, 5, 6]])

a.shape   →  (2, 3)     2 строки, 3 столбца
a.ndim    →  2          двумерный
a.size    →  6          всего элементов (2*3)
```

| обозначение | смысл |
|:---|:---|
| `shape[0]` | размер **оси 0** (обычно строки / batch) |
| `shape[1]` | размер **оси 1** (обычно столбцы / классы) |
| `shape[-1]` | последняя ось |

> shape — **не** функция: пишем `X.shape`, не `shape(X)`.

---

## 🔷 Где в домашке — главные формы

| объект | shape | смысл |
|:---|:---|:---|
| `train_X` | `(9000, 3073)` | 9000 картинок × 3073 признака |
| `train_y` | `(9000,)` | 9000 меток (цифры) |
| `W` | `(3073, 10)` | веса: признак × класс |
| `predictions` / logits | `(batch, 10)` | batch картинок × 10 цифр |
| `probs` | `(batch, 10)` | те же размеры после softmax |
| `dW` | `(3073, 10)` | градиент, форма как у W |

Цепочка:

```
X (9000, 3073)  @  W (3073, 10)  →  (9000, 10)
                                      ↑ shape[0]=картинки
                                      ↑ shape[1]=классы
```

---

## 🔷 Типичные обращения в коде

```python
num_train = X.shape[0]        # сколько объектов (строк)
num_features = X.shape[1]     # сколько признаков (столбцов)

batch_rows = np.arange(probs.shape[0])   # сколько строк в батче

np.ones((train_X.shape[0], 1))           # столбец единиц — по числу картинок

y_pred = np.zeros(X.shape[0], dtype=...)  # массив ответов — по числу test-картинок
```

## 🔷 1D vs 2D

| массив | shape | как читать |
|:---|:---|:---|
| вектор 10 классов | `(10,)` | одна ось, **10** элементов |
| одна «строка» с keepdims | `(1, 10)` | 1 строка, 10 столбцов |
| батч | `(300, 10)` | 300 строк, 10 столбцов |

> ⚠️ `(10,)` и `(10, 1)` — **разное**: первый — вектор, второй — столбец. Для broadcasting важно.

---

## 🔷 shape после операций

| операция | форма результата |
|:---|:---|
| `X @ W` | `(X.shape[0], W.shape[1])` |
| `softmax(predictions)` | **как у входа** |
| `X.T` | `(shape[1], shape[0])` — оси меняются местами |
| `reshape(n, -1)` | `-1` = «посчитай сам» (3072 → flatten) |

**Правило умножения матриц:**

```
(A, B) @ (B, C)  →  (A, C)
     ↑ внутренние B должны совпасть и исчезнуть
```

`(9000, 3073) @ (3073, 10) → (9000, 10)` ✓

---

## 🔷 Пример на цифрах

```python
probs.shape = (3, 10)     # 3 картинки, 10 классов

probs.shape[0]  →  3       # batch_size
probs.shape[1]  →  10      # num_classes

probs.ndim      →  2       # двумерный → softmax axis=1
```

Если `probs.shape = (10,)` — одна картинка, `ndim=1` → softmax `axis=0`.

---

## 🔷 Проверка в коде

```python
assert probs.shape == predictions.shape
assert dW.shape == W.shape
assert analytic_grad.shape == x.shape   # gradient_check
```

Если shape не совпали — ошибка до «странных» чисел в loss.

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `.shape` — кортеж размеров по осям |
| 2 | `shape[0]` — обычно batch/строки, `shape[1]` — признаки/классы |
| 3 | После `X @ W`: `(N, D) @ (D, K) → (N, K)` |
| 4 | softmax / grad — **та же shape**, что вход |
| 5 | `(10,)` ≠ `(10, 1)` — вектор vs столбец |
| 6 | `ndim` — число осей; 1D → axis=0, 2D batch → axis=1 в softmax |
