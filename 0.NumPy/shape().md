## 📌 Одна фраза

> **shape** — размеры массива: сколько элементов по каждой оси (без самих чисел внутри).

---

## 🔷 Что делает

У каждого numpy-массива есть атрибут `.shape` — **кортеж** длин по осям.

```python
a = np.array([[1, 2, 3],
              [4, 5, 6]])

a.shape   →  (2, 3)     2 строки, 3 столбца
a.ndim    →  2          двумерный
a.size    →  6          всего элементов (2*3)
```

| обозначение | смысл |
|:---|:---|
| `shape[0]` | размер **оси 0** |
| `shape[1]` | размер **оси 1** |
| `shape[-1]` | последняя ось |

> shape — **не** функция: пишем `X.shape`, не `shape(X)`.

---

## 🔷 1D vs 2D

| массив | shape | как читать |
|:---|:---|:---|
| вектор | `(10,)` | одна ось, **10** элементов |
| строка | `(1, 10)` | 1 строка, 10 столбцов |
| столбец | `(10, 1)` | 10 строк, 1 столбец |
| таблица | `(3, 10)` | 3 строки, 10 столбцов |

> ⚠️ `(10,)` и `(10, 1)` — **разное**: вектор vs столбец. Для broadcasting важно.

---

## 🔷 shape после операций

| операция | форма результата |
|:---|:---|
| `A @ B` | `(A.shape[0], B.shape[1])` — если внутренние совпали |
| `A.T` | оси меняются местами |
| `reshape(n, -1)` | `-1` = «посчитай сам» |

**Правило умножения матриц:**

```
(A, B) @ (B, C)  →  (A, C)
     ↑ внутренние B должны совпасть
```

---

## 🔷 Пример

```python
a = np.zeros((3, 10))
a.shape     →  (3, 10)
a.shape[0]  →  3
a.shape[1]  →  10
a.ndim      →  2
```

---

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `.shape` — кортеж размеров по осям |
| 2 | `(10,)` ≠ `(10, 1)` — вектор vs столбец |
| 3 | После `A @ B`: `(N, D) @ (D, K) → (N, K)` |
| 4 | `ndim` = число осей = `len(shape)` |
