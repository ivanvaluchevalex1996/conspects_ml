## 📌 Одна фраза

> Сортировка — `np.sort` (копия) и `a.sort()` (на месте); поиск — `nonzero`/`argwhere` (где ненулевые или `True`), `searchsorted` (позиция вставки), `partition` (k-й элемент без полной сортировки).

---

## 🔷 `np.sort` и `a.sort()`

```python
a = np.array([3, 1, 2])

np.sort(a)   # array([1, 2, 3])   — копия, a не трогает
a            # [3 1 2]

a.sort()     # сортирует НА МЕСТЕ, возвращает None
a            # [1 2 3]
```

> 💡 Индексы сортировки (не сам массив) — `np.argsort` (см. `2.функции 1D-массивов.md`).

### 2D — по оси

```python
X = np.array([[3, 1],
              [2, 4]])

np.sort(X, axis=1)   # [[1 3]     — по каждой строке (по умолчанию)
                     #  [2 4]]

np.sort(X, axis=0)   # [[2 1]     — по каждому столбцу
                     #  [3 4]]
```

---

## 🔷 `np.nonzero` — где ненулевые

Возвращает **кортеж** массивов индексов (по одному на ось):

```python
np.nonzero([0, 1, 0, 2])       # (array([1, 3]),)

X = np.array([[0, 1],
              [2, 0]])
np.nonzero(X)                  # (array([0, 1]), array([1, 0]))
```

> 💡 Работает и с булевыми массивами: `np.nonzero(mask)` = индексы `True`.

---

## 🔷 `np.argwhere` — координаты ненулевых

То же, но результат — **массив координат** `[[строка, столбец], ...]`:

```python
np.argwhere(np.array([[0, 1],
                      [2, 0]]))
# [[0 1]
#  [1 0]]
```

---

## 🔷 `np.searchsorted` — позиция вставки

В **отсортированный** массив возвращает индекс, куда вставить значение, чтобы порядок сохранился:

```python
sorted_arr = np.array([1, 3, 5, 7])

np.searchsorted(sorted_arr, 4)                # 2   — между 3 и 5
np.searchsorted(sorted_arr, 5)                # 2   — по умолчанию side='left'
np.searchsorted(sorted_arr, 5, side='right')  # 3
np.searchsorted(sorted_arr, [0, 6])           # [0 3]
```

---

## 🔷 `np.partition` — k-й элемент без полной сортировки

Ставит k-й по возрастанию элемент на своё место: слева — меньшие, справа — большие (порядок внутри половин не гарантирован). **Быстрее** полной сортировки.

```python
a = np.array([7, 1, 5, 3, 9])

np.partition(a, 2)
# на позиции 2 окажется 5 (третий по возрастанию);
# слева — меньшие, справа — большие

np.argpartition(a, 2)   # индексы для такого же расклада
```

> 💡 Удобно, чтобы взять топ-k, не сортируя весь массив.

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `np.sort(a)` — копия; `a.sort()` — на месте (возвращает `None`) |
| 2 | 2D: `axis=1` — по строкам (по умолчанию), `axis=0` — по столбцам |
| 3 | `argsort` — индексы сортировки (см. `2.функции 1D-массивов.md`) |
| 4 | `nonzero` — кортеж индексов; `argwhere` — массив координат |
| 5 | `searchsorted` — позиция вставки в отсортированный массив |
| 6 | `partition(a, k)` — k-й элемент на месте, быстрее `sort` |
