## 📌 Одна фраза

> `np.zeros` создаёт массив, **заполненный нулями** заданной формы.

---

## 🔷 Что делает

```python
np.zeros(форма)              →  массив той же формы, везде 0.0
np.zeros((строки, столбцы))  →  таблица из нулей
```

| вызов | результат |
|:---|:---|
| `np.zeros(5)` | `[0., 0., 0., 0., 0.]` |
| `np.zeros((3, 2))` | матрица 3×2 из нулей |
| `np.zeros(3, dtype=int)` | `[0, 0, 0]` |

> 💡 Брат-близнец `np.ones` — та же форма, но единицы. `np.zeros_like(x)` — нули **той же формы**, что `x`.

---

## 🔷 ones vs zeros

| функция | чем заполняет |
|:---|:---|
| `np.ones` | **1** |
| `np.zeros` | **0** |

---

## 🔷 Синтаксис

```
np.zeros(shape, dtype=float)
```

| Параметр | Значение |
|:---|:---|
| `shape` | число или кортеж `(строки, столбцы)` |
| `dtype` | тип (по умолчанию **float** → `0.0`) |

```python
np.zeros(5)
np.zeros((3, 4))
np.zeros_like(a)   # форма и dtype как у a
```

> ⚠️ `np.zeros(9000, 10)` — **ошибка**. Нужен кортеж: `np.zeros((9000, 10))`.

---

## 🔷 Пример

```python
a = np.zeros(4, dtype=int)
# [0, 0, 0, 0]

a[0] = 7
a[1] = 2
# [7, 2, 0, 0]
```

```python
b = np.zeros((3, 2))
# [[0., 0.],
#  [0., 0.],
#  [0., 0.]]
```

---

## 🔷 dtype

```python
np.zeros(3)            →  [0., 0., 0.]     float64
np.zeros(3, dtype=int) →  [0, 0, 0]       int
```

---

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `zeros` — массив из **нулей** заданной формы |
| 2 | 2D — только кортеж: `zeros((N, K))` |
| 3 | По умолчанию float; для целых — `dtype=int` |
| 4 | `zeros_like(a)` — нули той же формы, что `a` |
