---

## 📌 Одна фраза

> `np.random.randint` — **случайные целые** из полуинтервала `[low, high)`.

---

## 🔷 Что делает

```python
np.random.randint(low, high=None, size=None, dtype=int)
```

Главное правило диапазона:

```
low <= число < high
```

- нижняя граница **включена** (`low`)
- верхняя **не включена** (`high`)

| вызов | результат |
|:---|:---|
| `np.random.randint(5)` | одно число: 0, 1, 2, 3 или 4 |
| `np.random.randint(2, 10)` | одно число: 2 .. 9 |
| `np.random.randint(0, 3)` | 0, 1 или 2 (**тройки не будет**) |
| `np.random.randint(0, 10, size=(3, 4))` | матрица 3×4, числа 0..9 |

---

## 🔷 Варианты вызова

**Одно число:**

```python
np.random.randint(5)       # от 0 до 4
np.random.randint(2, 10)   # от 2 до 9
```

Если один аргумент — это `high`, `low` по умолчанию 0.

**Массив:**

```python
np.random.randint(0, 10, size=(3, 4))
# матрица 3×4 со случайными числами от 0 до 9
```

---

## 🔷 Частая ошибка

```python
# хочу числа 1, 2, 3
np.random.randint(1, 3)   # ❌ только 1 и 2
np.random.randint(1, 4)   # ✅ 1, 2, 3
```

Верхняя граница **не входит**.

---

## 🔷 randint vs random

|    | `randint` | `random` / `rand` |
|:---|:---|:---|
| тип | **целые** | **дробные** |
| диапазон | `[low, high)` | только `[0, 1)` |

---

## 🔷 Новый API (рекомендуется)

В новых версиях NumPy лучше так:

```python
rng = np.random.default_rng(42)   # 42 — seed
rng.integers(0, 10, size=(5,))
```

`rng.integers` работает так же: нижняя включена, верхняя — нет.

---

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `randint` — случайные **целые** |
| 2 | Диапазон `[low, high)` — high **не входит** |
| 3 | Один аргумент = upper: `randint(5)` → 0..4 |
| 4 | Массив: `size=(строки, столбцы)` |
| 5 | Современнее: `default_rng().integers(...)` |
