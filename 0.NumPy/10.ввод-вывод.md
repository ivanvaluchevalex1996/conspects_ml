## 📌 Одна фраза

> Числовые массивы сохраняют в **бинарный** формат: `.npy` — один массив, `.npz` — несколько. `np.save` / `np.load` / `np.savez` — быстро и с сохранением shape/dtype.

---

## 🔷 `np.save` / `np.load` — один массив (`.npy`)

Сохраняет и **форму**, и **dtype** — читается обратно «как было»:

```python
arr = np.array([[1, 2], [3, 4]])

np.save('arr.npy', arr)      # создаёт arr.npy
b = np.load('arr.npy')
b                            # [[1 2] [3 4]]  — тот же shape и dtype
```

> ⚠️ `np.save('arr', arr)` сам добавит расширение `.npy`.

---

## 🔷 `np.savez` / `np.savez_compressed` — несколько массивов (`.npz`)

Сохраняет **именованные** массивы; читаются как словарь:

```python
np.savez('data.npz', x=x, y=y)

d = np.load('data.npz')
d['x'], d['y']

np.savez_compressed('data.npz', x=x, y=y)   # то же, но со сжатием
```

---

> 💡 Текст/CSV — обычно через `pandas.read_csv`; здесь NumPy только про **бинарные** `.npy` / `.npz`.

---

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `np.save`/`np.load` — один массив, формат `.npy` (хранит shape и dtype) |
| 2 | `np.savez`/`savez_compressed` — несколько массивов, `.npz`, доступ по ключу |
| 3 | `.npy`/`.npz` — быстрее и точнее текстовых форматов |
