---

## 📌 Одна фраза

> **dtype** — тип **всех** элементов массива; **astype** — сделать **копию** массива с другим типом.

---

## 🔷 dtype — что это

В NumPy у массива **один** тип на весь массив (не как у list Python).

```python
a = np.array([1, 2, 3])
a.dtype    →  int64 (или int32)     целые

b = np.array([1.0, 2.5])
b.dtype    →  float64               дробные
```

Смотреть тип: `a.dtype`.  
Задать при создании: `np.array(..., dtype=...)`, `np.zeros(..., dtype=...)`.

---

## 🔷 Частые типы

| dtype | смысл |
|:---|:---|
| `int`, `int32`, `int64` | целые |
| `float`, `float32`, `float64` | дробные |
| `bool` | True / False |
| `str` / `U...` | строки |

По умолчанию чаще всего: целые → `int64` (или `int32` на системе), дробные → `float64`.

---

## 🔷 Смешанные типы → повышение

Если в списке и целые, и дробное — **весь** массив станет дробным:

```python
np.array([1, 2, 3, 1.5])
# array([1. , 2. , 3. , 1.5])  dtype=float64
```

Почему: нужен **один** тип, в котором можно хранить всё без потерь.

```
int  → float  можно (3 → 3.0)
float → int   без потери нельзя (1.5 → ?)
```

Порядок «силы» (упрощённо): `bool` < `int` < `float` < `str`.

Ошибки нет — NumPy сам **повышает** тип (upcasting).

---

## 🔷 astype — сменить тип

```python
a.astype(новый_тип)   →  новый массив, числа приведены к типу
```

Исходный массив **не меняется** — возвращается **копия**.

```python
a = np.array([1.7, 2.3, 3.9])
a.dtype              →  float64

b = a.astype(int)
b                    →  array([1, 2, 3])   # дробная часть отброшена
b.dtype              →  int64

a                    →  всё ещё [1.7, 2.3, 3.9]  # оригинал цел
```

| вызов | смысл |
|:---|:---|
| `a.astype(float)` | целые → дробные (`3` → `3.0`) |
| `a.astype(int)` | дробные → целые (**обрезание**, не округление!) |
| `a.astype(bool)` | 0 → False, остальное → True |
| `a.astype(np.float32)` | тот же смысл, меньшая точность / меньше памяти |

---

## 🔷 dtype при создании vs astype

| способ | когда |
|:---|:---|
| `np.array([1, 2], dtype=float)` | сразу создать нужного типа |
| `np.zeros(5, dtype=int)` | нули сразу целые |
| `a.astype(float)` | уже есть массив — сменить тип |

```python
np.array([1, 2, 3], dtype=float)   # [1., 2., 3.]
np.array([1, 2, 3]).astype(float)  # то же, но через копию
```

---

## 🔷 Частые ошибки

| ошибка | почему |
|:---|:---|
| ждать округления от `astype(int)` | `1.9 → 1`, не `2` (просто отрезает) |
| ждать, что `a.astype(...)` изменит `a` | меняется только результат; `a` прежний |
| думать, что в массиве могут жить разные типы | dtype **один** на всех |

---

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `dtype` — тип всех элементов массива |
| 2 | int + float в одном array → весь массив **float** |
| 3 | `astype` — копия с новым типом, оригинал не трогает |
| 4 | `astype(int)` — **обрезает** дробную часть, не округляет |
| 5 | Тип задают при создании (`dtype=...`) или после (`astype`) |
