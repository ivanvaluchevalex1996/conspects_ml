## 📌 Одна фраза

> `np.ones` создаёт массив, **заполненный единицами** заданной формы.

---

## 🔷 Что делает

```python
np.ones(форма)              →  массив той же формы, везде 1.0
np.ones((строки, столбцы))  →  таблица из единиц
```

| вызов | результат |
|:---|:---|
| `np.ones(5)` | `[1., 1., 1., 1., 1.]` |
| `np.ones((3, 2))` | матрица 3×2 из единиц |

> 💡 Аналог: `np.zeros` — то же, но нули. `np.ones_like(x)` — единицы **той же формы**, что `x`.

---

## 🔷 Синтаксис

```
np.ones(shape, dtype=float)
```

| Параметр | Значение |
|:---|:---|
| `shape` | число или кортеж `(строки, столбцы)` |
| `dtype` | тип (по умолчанию float) |

```python
np.ones(5)
np.ones((3, 1))      # столбец из трёх единиц
np.ones_like(a)
```

> ⚠️ `np.ones(9000, 1)` — **ошибка**. Нужен кортеж: `np.ones((9000, 1))`.

---

## 🔷 Пример

```python
np.ones((3, 1))
# [[1.],
#  [1.],
#  [1.]]
```

Склеить с другой матрицей по столбцам:

```python
np.hstack([A, np.ones((A.shape[0], 1))])
```

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `ones` — массив из единиц заданной формы |
| 2 | 2D — только кортеж: `ones((N, K))` |
| 3 | `ones_like(a)` — единицы той же формы, что `a` |
