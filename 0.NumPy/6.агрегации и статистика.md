## 📌 Одна фраза

> Агрегации **сворачивают** массив вдоль оси: базовые (`sum`/`mean`/`min`/`max`/`prod`/`std`/`var`/`median`), квантили (`percentile`/`quantile`), взвешенное среднее (`average`), накопительные (`cumsum`/`cumprod`) и логические (`all`/`any`/`count_nonzero`).

---

## 🔷 Базовые агрегации

```python
a = np.array([1, 2, 3, 4, 5])

a.sum()        # 15
a.mean()       # 3.0
a.min()        # 1
a.max()        # 5
a.prod()       # 120                   — произведение
a.std()        # 1.4142135623730951    — стандартное отклонение
a.var()        # 2.0                   — дисперсия

np.median(a)   # 3.0                   — только функцией!
```

| функция | что считает |
|:---|:---|
| `sum` / `prod` | сумма / произведение |
| `min` / `max` | минимум / максимум |
| `mean` | среднее |
| `std` / `var` | стандартное отклонение / дисперсия |
| `median` | медиана |
| `argmin` / `argmax` | **индекс** min / max (см. `2.функции 1D-массивов.md`) |

> 💡 У `sum`/`mean`/`std`/`var`/`prod`/`min`/`max` есть и метод (`a.sum()`), и функция (`np.sum(a)`). У `median`/`percentile`/`quantile`/`average` — **только функция**.

> ⚠️ `std` / `var` по умолчанию делят на `n` (`ddof=0`); для выборочной оценки — `ddof=1`.

---

## 🔷 Вдоль оси — `axis` и `keepdims`

`axis` — какую ось **схлопываем** (подробно — `4.многомерные массивы.md`):

```python
X = np.array([[1, 2, 3],
              [4, 5, 6]])

X.sum(axis=0)    # [5 7 9]     — по столбцам
X.mean(axis=1)   # [2. 5.]     — по строкам
X.std(axis=0)    # [1.5 1.5 1.5]
```

---

## 🔷 Квантили: `median` / `percentile` / `quantile`

```python
a = np.array([1, 2, 3, 4, 5])

np.median(a)                     # 3.0        — 50-й процентиль
np.percentile(a, 25)             # 2.0        — в процентах (0..100)
np.percentile(a, [25, 50, 75])   # [2. 3. 4.]

np.quantile(a, 0.5)              # 3.0        — в долях (0..1)
np.quantile(a, [0.25, 0.75])     # [2. 4.]
```

> 💡 `percentile` — проценты, `quantile` — доли; `median(a)` ≡ `percentile(a, 50)`.

---

## 🔷 Взвешенное среднее: `average`

```python
values  = np.array([1, 2, 3, 4])
weights = np.array([4, 3, 2, 1])

np.average(values, weights=weights)   # 2.0
# (1*4 + 2*3 + 3*2 + 4*1) / (4+3+2+1) = 20 / 10
```

---

## 🔷 Накопительные: `cumsum` / `cumprod`

```python
np.cumsum([1, 2, 3, 4])    # [1 3 6 10]     — нарастающая сумма
np.cumprod([1, 2, 3, 4])   # [1 2 6 24]     — нарастающее произведение
```

---

## 🔷 Логические: `all` / `any` / `count_nonzero`

```python
a = np.array([1, 2, 3, 4, 5])

np.all(a > 0)                    # True    — все элементы?
np.any(a > 4)                    # True    — хотя бы один?
np.count_nonzero([0, 1, 2, 0])   # 2       — сколько ненулевых (или True)
```

---

## 🔷 Частоты: `bincount` / `histogram`

```python
np.bincount([0, 1, 1, 3])       # [1 2 0 1]   — счётчик целых 0..max

hist, edges = np.histogram([1, 2, 3, 4], bins=2)
# hist:  [2 2]
# edges: [1.  2.5 4. ]
```

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | Базовые: `sum`/`mean`/`min`/`max`/`prod`/`std`/`var`/`median` |
| 2 | Работают как метод `a.sum(...)` и как функция `np.sum(a, ...)` |
| 3 | `median`/`percentile`/`quantile`/`average` — **только функция** |
| 4 | `axis` — какую ось схлопываем; `keepdims=True` сохраняет ось размером 1 |
| 5 | `percentile` — %, `quantile` — доли; `median` = `percentile(50)` |
| 6 | `average(values, weights=...)` — взвешенное среднее |
| 7 | `cumsum`/`cumprod` — накопительные; `all`/`any`/`count_nonzero` — логические |
| 8 | `std`/`var`: делят на `n`; для выборочных — `ddof=1` |
