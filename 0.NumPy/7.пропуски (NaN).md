## 📌 Одна фраза

> `NaN` «заражает» любую агрегацию — обычные `sum`/`mean` вернут `nan`. Для пропусков есть детекторы (`isnan`/`isinf`/`isfinite`), nan-версии агрегаций (`nanmean`/`nansum`/…) и замена/удаление (`nan_to_num`, маска).

---

## 🔷 `NaN` — не число

`np.nan` (Not a Number) — маркер пропуска. Ключевая особенность: **`nan` не равен самому себе**.

```python
np.nan == np.nan     # False
np.nan != np.nan     # True
```

> ⚠️ Поэтому сравнивать нельзя через `==` — только `np.isnan`.

---

## 🔷 Детекторы

```python
a = np.array([1.0, np.nan, 3.0])

np.isnan(a)      # [False  True False]
np.isfinite(a)   # [ True False  True]   — обычное число (не NaN и не ∞)

np.isinf(np.array([1.0, np.inf, -np.inf]))   # [False  True  True]
```

| функция | `True`, когда… |
|:---|:---|
| `np.isnan(x)` | `x` — NaN |
| `np.isinf(x)` | `x` — ±∞ |
| `np.isfinite(x)` | обычное число (не NaN и не ∞) |

> 💡 Сколько пропусков: `np.isnan(a).sum()` или `np.count_nonzero(np.isnan(a))`.

---

## 🔷 `NaN` «ломает» обычные агрегации

```python
a = np.array([1.0, np.nan, 3.0])

a.sum()      # nan
a.mean()     # nan
```

Одно `nan` — и результат `nan`. Решение — **nan-версии**, которые пропуски **игнорируют**:

```python
np.nansum(a)     # 4.0
np.nanmean(a)    # 2.0
np.nanmin(a)     # 1.0
np.nanmax(a)     # 3.0
np.nanstd(a)     # 1.0    — считает по «живым» 1 и 3
```

| обычная | nan-версия |
|:---|:---|
| `sum` / `mean` | `nansum` / `nanmean` |
| `min` / `max` | `nanmin` / `nanmax` |
| `std` / `var` | `nanstd` / `nanvar` |
| `median` | `nanmedian` |

## 🔷 Убрать / заменить `NaN`

### Замена: `np.nan_to_num`

```python
a = np.array([1.0, np.nan, 3.0])

np.nan_to_num(a)              # [1. 0. 3.]     — nan → 0.0
np.nan_to_num(a, nan=-1)      # [ 1. -1.  3.]  — свой заменитель
# есть также posinf= / neginf= для ±∞
```

### Удаление: булева маска

```python
a = np.array([1.0, np.nan, 3.0])
a[~np.isnan(a)]     # [1. 3.]   — только «живые» значения
```

> 💡 Это булева маска — подробнее в `3.индексация и срезы.md`.

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `nan != nan` → сравнивать только через `np.isnan` |
| 2 | Любая обычная агрегация с `nan` даёт `nan` |
| 3 | Nan-версии `nansum`/`nanmean`/`nanstd`/`nanmedian` — игнорируют пропуски |
| 4 | Детекторы: `isnan`/`isinf`/`isfinite`; счёт — `isnan(a).sum()` |
| 5 | `nan_to_num(a, nan=...)` — заменить; `a[~np.isnan(a)]` — выбросить |
