> Форма и `reshape` — в `4.многомерные массивы.md`.

## 🔷 `np.unique` — уникальные значения

Возвращает **отсортированный** массив без повторов:

```python
arr = np.array([3, 1, 2, 3, 2, 1, 4, 3, 2, 9, 5])
np.unique(arr)  # [1 2 3 4 5 9]
```

| параметр | что ещё возвращает |
|:---|:---|
| `return_counts=True` | сколько раз каждое значение |
| `return_index=True` | индекс **первого** вхождения |
| `return_inverse=True` | индексы, чтобы восстановить исходный из unique |

```python
values, counts = np.unique(arr, return_counts=True)
# values: [1 2 3 4 5 9]
# counts: [2 3 3 1 1 1]

values, indices = np.unique(arr, return_index=True)
# indices — где впервые встретились values
# arr[indices] == values

values, inverse = np.unique(arr, return_inverse=True)
# values[inverse] → снова исходный arr
```

## 🔷 `np.argsort` — индексы для сортировки

Не сортирует сам массив — возвращает **порядок индексов**, в котором элементы идут по возрастанию:

```python
arr = np.array([10, 5, 8, 3, 12])
idx = np.argsort(arr)   # [3 1 2 0 4]
arr[idx]                # [3 5 8 10 12]

arr[np.argsort(arr)[::-1]]  # по убыванию: [12 10 8 5 3]
```

Практика — отсортировать **один** массив по порядку **другого**:

```python
students = np.array(['Алексей', 'Елена', 'Дмитрий', 'Ольга', 'Сергей'])
grades = np.array([85, 92, 78, 95, 88])

order = np.argsort(grades)
students[order]  # по возрастанию оценок
grades[order]
```

## 🔷 `np.argmin` / `np.argmax` — индекс min / max

Индекс **первого** вхождения минимума или максимума:

```python
arr = np.array([10, 5, 8, 3, 12, 3])

np.argmin(arr)  # 3  → arr[3] == 3
np.argmax(arr)  # 4  → arr[4] == 12
```

| функция | возвращает |
|:---|:---|
| `np.min` / `np.max` | **значение** |
| `np.argmin` / `np.argmax` | **индекс** |
| `np.argsort` | индексы **всех** элементов в порядке сортировки |

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `unique` — уникальные **отсортированные**; есть counts / index / inverse |
| 2 | `argsort` — индексы порядка; удобно сортировать пару массивов |
| 3 | `argmin` / `argmax` — индекс первого min / max |
