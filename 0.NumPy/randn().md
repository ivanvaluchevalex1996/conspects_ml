## 📌 Одна фраза

> `randn` создаёт массив **случайных чисел из нормального распределения** (среднее \~0, разброс \~1).

---

## 🔷 Что делает

```python
np.random.randn()              →  одно число (float)
np.random.randn(5)             →  5 случайных чисел
np.random.randn(3, 2)          →  матрица 3×2 случайных чисел
```

Числа **разные каждый запуск** (если не зафиксировать seed).

Типичный вид — около нуля, плюс и минус:

```
[-0.23,  1.05, -0.87,  0.41, -1.12]
```

| свойство | значение |
|:---|:---|
| распределение | **нормальное** (гауссово) |
| среднее | около **0** |
| типичный разброс | большинство между **-2** и **+2** |

> 💡 **randn** = **rand** + **n** (normal). Не путать с `np.random.rand` — там **равномерное** от 0 до 1.

---

## 🔷 Синтаксис

```
np.random.randn(d0, d1, d2, ...)
```

| вызов | shape |
|:---|:---|
| `randn()` | скаляр |
| `randn(10)` | `(10,)` |
| `randn(3, 2)` | `(3, 2)` |

> Можно и кортежем: `randn(*(3, 2))` — обычно пишут просто `randn(3, 2)`.

---

## 🔷 randn vs rand vs randint

| функция | что выдаёт | диапазон / тип |
|:---|:---|:---|
| `randn(...)` | нормальное | \~(-3, +3), float |
| `rand(...)` | равномерное | **[0, 1)**, float |
| `randint(a, b, size=...)` | целые | **[a, b)**, int |

---

## 🔷 Пример

```python
np.random.seed(42)   # чтобы числа повторялись
a = np.random.randn(2, 3)
```

Возможный результат:

```
[[ 0.05, -1.23,  0.88],
 [ 0.67, -0.34,  1.01]]
```

---

## 🔷 seed — воспроизводимость

```python
np.random.seed(42)
a = np.random.randn(3, 2)
np.random.seed(42)
b = np.random.randn(3, 2)
# a и b одинаковые
```

Без seed — каждый запуск другие числа.

---

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `randn` — случайные float из **нормального** распределения (\~0, \~±1) |
| 2 | Не путать: `randn` (normal) ≠ `rand` (0..1) ≠ `randint` (целые) |
| 3 | `seed` — чтобы результат повторялся |
