## 📌 Одна фраза

> **axis** — по какой оси **схлопываем** массив при `max`, `sum`, `mean`: какую «линию» складываем или ищем максимум.

---

## 🔷 Что делает

```python
np.max(A, axis=...)    # максимум вдоль оси
np.sum(A, axis=...)    # сумма вдоль оси
np.mean(A, axis=0)     # среднее в ноутбуке — по пикселям
```

**axis = какую ось убиваем.** Остальные оси остаются.

> ⚠️ **Наоборот от интуиции «строка/столбец»:**
>
> - `axis=0` → идём **вниз** по столбцу → схлопнули **строки**
> - `axis=1` → идём **вправо** по строке → схлопнули **столбцы**

---

## 🔷 Оси от 0 слева направо

| размерность | shape | ось 0 | ось 1 | ось 2 |
|:---|:---|:---|:---|:---|
| 1D | `(10,)` | 10 элементов | — | — |
| 2D | `(100, 10)` | 100 **строк** (картинки) | 10 **столбцов** (цифры) | — |
| 3D | `(2, 3, 4)` | 2 «стопки» | 3 строки | 4 числа в строке |

Оси нумеруются **0, 1, 2, ...** до `ndim - 1`.
Для `(100, 10)` есть только `axis=0` и `axis=1`. `axis=2` — ошибка.

---

## 🔷 2D таблица (100, 10) — главное для домашки

100 картинок, 10 цифр:

```
        цифра0  цифра1  ...  цифра9
фото 0    ...     ...    ...    ...
фото 1    ...     ...    ...    ...
...
```

| axis | схлопываем | идём | остаётся | смысл |
|:---|:---|:---|:---|:---|
| **0** | строки (100→1) | ↓↓↓ вниз по столбцу | 1 число **на столбец** | смешать разные фото |
| **1** | столбцы (10→1) | →→→ вправо по строке | 1 число **на строку** | 10 цифр **одной** картинки |

---

## 🔷 Пример axis=0 vs axis=1 (2×3)

```
X = [[1, 2, 0],
     [3, 1, 1]]
```

### max(axis=0) — по столбцам, вниз

```
столбец0: max(1, 3) = 3
столбец1: max(2, 1) = 2
столбец2: max(0, 1) = 1

→ [3, 2, 1]     форма (3,)
```

### max(axis=1) — по строкам, вправо

```
строка0: max(1, 2, 0) = 2
строка1: max(3, 1, 1) = 3

→ [2, 3]        форма (2,)
```

---

## 🔷 Где в домашке

| место | axis | зачем |
|:---|:---|:---|
| `softmax` 2D | **1** | max/sum по 10 классам **внутри строки** (одна картинка) |
| `softmax` 1D | **0** | одна ось — по всем классам |
| `np.mean(train_flat, axis=0)` | **0** | среднее **по картинкам** для каждого пикселя (нормализация) |
| `dprediction /= probs.shape[0]` | — | делим градиент; не axis, но связано с batch |

**Softmax — только axis=1 для батча:**

```python
if predictions.ndim == 1:
    axis = 0
else:
    axis = 1
stable = predictions - np.max(predictions, axis=axis, keepdims=True)
```

`axis=0` на `(100, 10)` смешал бы 100 разных фото в одном столбце — **не то**.

---

## 🔷 keepdims=True

Без keepdims:

```
(100, 10) - max(axis=1)     →  (100, 10) - (100,)   ❌ формы не стыкуются
```

С keepdims:

```
max(axis=1, keepdims=True)  →  (100, 1)

строка 0: [10 чисел] - [max строки 0]
строка 1: [10 чисел] - [max строки 1]
```

Numpy «размазывает» `(100, 1)` на 10 столбцов.

---

## 🔷 3D — если axis=0, 1, 2

Форма `(2, 3, 4)` — две таблицы 3×4:

| axis | схлопнули | осталось |
|:---|:---|:---|
| 0 | 2 стопки → 1 | `(3, 4)` |
| 1 | 3 строки → 1 | `(2, 4)` |
| 2 | 4 числа в строке → 1 | `(2, 3)` |

`axis=0` на 3D — две «стопки» в одну таблицу: в каждой клетке max/sum **по стопкам**.

> В домашке логиты `(batch, 10)` — **2D**, 3D не нужен.

---

## 🔷 axis=2 на 2D — ошибка

```
shape (100, 10), ndim = 2
axis=2  →  AxisError: axis 2 is out of bounds
```

Третья ось появляется только у 3D+ массивов.

---

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | axis — **какую ось схлопываем** |
| 2 | `axis=0` → вниз, по столбцам; `axis=1` → вправо, по строкам |
| 3 | softmax батч `(N, 10)` → **axis=1** |
| 4 | softmax одна картинка `(10,)` → **axis=0** |
| 5 | `keepdims=True` — оставить ось размером 1 для вычитания |
| 6 | `axis=2` только если `ndim >= 3` |
| 7 | Подсказка: **убиваем ось** → живые оси = те, что остались |
