---

## 📌 Одна фраза

> `reshape` **меняет форму** массива, не трогая сами числа.

---

## 🔷 Что делает

```python
a.reshape(новая_форма)     # метод массива
np.reshape(a, новая_форма) # то же функцией
```

Числа **те же**, меняется только «как разложены по осям».

| до | после reshape |
|:---|:---|
| `(2, 3)` | `(3, 2)` или `(6,)` |
| `(2, 2, 3)` | `(2, 6)` |

> ⚠️ Число элементов **не меняется**: `до.size == после.size`. Иначе ошибка.

---

## 🔷 Синтаксис и `-1`

```
массив.reshape(d0, d1, ...)
массив.reshape((d0, d1, ...))
```

| параметр | смысл |
|:---|:---|
| числа `d0, d1, ...` | новые размеры по осям |
| `-1` | **одна** ось: numpy сам посчитает длину |

```python
a = np.arange(12)          # shape (12,)
a.reshape(3, 4)            # (3, 4)
a.reshape(2, -1)           # (2, 6)  — 12/2 = 6
a.reshape(-1, 3)           # (4, 3)  — 12/3 = 4
```

---

## 🔷 Пример

```python
a = np.array([[1, 2, 3],
              [4, 5, 6]])   # (2, 3)

a.reshape(3, 2)
# [[1, 2],
#  [3, 4],
#  [5, 6]]

a.reshape(6)               # [1, 2, 3, 4, 5, 6]
```

Порядок по умолчанию — по строкам (C-order): слева направо, сверху вниз.

---

## 🔷 Связь с shape

|    |    |
|:---|:---|
| `.shape` | **смотреть** размеры |
| `.reshape(...)` | **менять** размеры |

Правило: произведение размеров до = произведению после.

```
(2, 3, 4) → size 24
reshape(6, 4) ✓
reshape(5, 5) ✗  — 25 ≠ 24
```

---

## 🔷 Частые ошибки

| ошибка | почему |
|:---|:---|
| `reshape` с другим `size` | число элементов должно совпасть |
| путать с `resize` | `resize` **может** менять число элементов |

---

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `reshape` меняет **форму**, не сами числа |
| 2 | `size` до и после должен совпасть |
| 3 | `-1` = «посчитай эту ось сам» |
