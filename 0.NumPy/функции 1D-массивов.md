> `reshape` уже в отдельном конспекте — здесь только то, чего там нет.

## 🔷 `np.resize` vs `arr.resize` vs `reshape`

|    | меняет `size`? | исходный массив | чем заполняет при увеличении |
|:---|:---|:---|:---|
| **`reshape`** | **нет** (только форма) | новый вид / копия | — ошибка, если size другой |
| **`np.resize(arr, n)`** | да | **не трогает**, возвращает новый | **повторяет** элементы по кругу |
| **`arr.resize(n)`** | да | **меняет на месте** | **нули** |

### `np.resize(arr, new_shape)` — новый массив

Уменьшение — обрезка с начала. Увеличение — цикл с начала:

```python
arr = np.array([1, 2, 3])

np.resize(arr, 6)  # [1 2 3 1 2 3]
np.resize(arr, 1)  # [1]
print(arr)         # [1 2 3] — исходный цел
```

### `arr.resize(new_shape)` — на месте

```python
arr = np.array([1, 2, 3])
arr.resize(1)
print(arr)   # [1]

arr.resize(6)
print(arr)   # [1 0 0 0 0 0]  — добили нулями, не циклом
```

> ⚠️ Не путать: `np.resize` ≠ `arr.resize` (повтор vs нули) ≠ `reshape` (size тот же).

## 🔷 `np.unique` — уникальные значения

Возвращает **отсортированный** массив без повторов:

```python
arr = np.array([3, 1, 2, 3, 2, 1, 4, 3, 2, 9, 5])
np.unique(arr)  # [1 2 3 4 5 9]
```

| параметр | что ещё возвращает |
|:---|:---|
| `return_counts=True` | сколько раз каждое значение |
| `return_index=True` | индекс **первого** вхождения |
| `return_inverse=True` | индексы, чтобы восстановить исходный из unique |

```python
values, counts = np.unique(arr, return_counts=True)
# values: [1 2 3 4 5 9]
# counts: [2 3 3 1 1 1]

values, indices = np.unique(arr, return_index=True)
# indices — где впервые встретились values
# arr[indices] == values

values, inverse = np.unique(arr, return_inverse=True)
# values[inverse] → снова исходный arr
```

## 🔷 `np.append` — добавить в конец

Новый массив, исходный не меняется:

```python
arr = np.array([1, 2, 3])
np.append(arr, 4)         # [1 2 3 4]
np.append(arr, [4, 5, 6]) # [1 2 3 4 5 6]
```

---

## 🔷 `np.insert` — вставить по позиции

Вставляет **перед** указанным индексом. Новый массив:

```python
arr = np.array([1, 2, 3, 4])

np.insert(arr, 3, 5)              # [1 2 3 5 4]
np.insert(arr, [1, 3], 6)         # [1 6 2 3 6 4]
np.insert(arr, 2, [10, 20])       # [1 2 10 20 3 4]
np.insert(arr, [1, 3], [100, 200]) # [1 100 2 3 200 4]
```

---

## 🔷 `np.delete` — удалить по индексам

Новый массив:

```python
arr = np.array([10, 20, 30, 40, 50])

np.delete(arr, 2)           # [10 20 40 50]
np.delete(arr, [1, 3])      # [10 30 50]
np.delete(arr, slice(1, 4)) # [10 50]
```

> `append` / `insert` / `delete` всегда **копия**. Массивы NumPy фиксированной длины — «добавить элемент» = создать новый.

## 🔷 `np.argsort` — индексы для сортировки

Не сортирует сам массив — возвращает **порядок индексов**, в котором элементы идут по возрастанию:

```python
arr = np.array([10, 5, 8, 3, 12])
idx = np.argsort(arr)   # [3 1 2 0 4]
arr[idx]                # [3 5 8 10 12]

arr[np.argsort(arr)[::-1]]  # по убыванию: [12 10 8 5 3]
```

Практика — отсортировать **один** массив по порядку **другого**:

```python
students = np.array(['Алексей', 'Елена', 'Дмитрий', 'Ольга', 'Сергей'])
grades = np.array([85, 92, 78, 95, 88])

order = np.argsort(grades)
students[order]  # по возрастанию оценок
grades[order]
```

## 🔷 `np.argmin` / `np.argmax` — индекс min / max

Индекс **первого** вхождения минимума или максимума:

```python
arr = np.array([10, 5, 8, 3, 12, 3])

np.argmin(arr)  # 3  → arr[3] == 3
np.argmax(arr)  # 4  → arr[4] == 12
```

| функция | возвращает |
|:---|:---|
| `np.min` / `np.max` | **значение** |
| `np.argmin` / `np.argmax` | **индекс** |
| `np.argsort` | индексы **всех** элементов в порядке сортировки |

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `reshape` — тот же size; `resize` — size может меняться |
| 2 | `np.resize` → повтор по кругу; `arr.resize` → нули, in-place |
| 3 | `unique` — уникальные **отсортированные**; есть counts / index / inverse |
| 4 | `append` / `insert` / `delete` — всегда новый массив |
| 5 | `argsort` — индексы порядка; удобно сортировать пару массивов |
| 6 | `argmin` / `argmax` — индекс первого min / max |
