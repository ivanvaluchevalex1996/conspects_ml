## 📌 Одна фраза

> Массивы создают из готовых данных (`np.array`), из диапазона (`np.arange`) или «пустыми» шаблонами (`np.zeros`, `np.ones`). Тип всех элементов задаёт `dtype`, а меняют его через `astype`.

---

## 🔷 `np.array` — из готовых данных

Собирает массив из списка (или вложенных списков → многомерный):

```python
np.array([1, 2, 3])          # [1 2 3]     — 1D
np.array([[1, 2], [3, 4]])   # (2, 2)      — 2D
```

---

## 🔷 `np.arange` — последовательность с шагом

`np.arange` — **последовательность чисел** с заданным шагом (как `range`, но сразу numpy-массив).

```python
np.arange(stop)              →  0, 1, 2, ..., stop-1
np.arange(start, stop)       →  start, ..., stop-1   (stop не входит!)
np.arange(start, stop, step) →  start, start+step, ...  пока < stop
```

| вызов | результат |
|:---|:---|
| `np.arange(5)` | `[0, 1, 2, 3, 4]` |
| `np.arange(2, 5)` | `[2, 3, 4]` |
| `np.arange(0, 10, 3)` | `[0, 3, 6, 9]` |
| `np.arange(32, 100, 32)` | `[32, 64, 96]` |

> ⚠️ **`stop` не включается** — как срез `a[start:stop]`.

> 💡 Не путать с `range()` Python — `arange` сразу даёт **numpy-массив**.

### `arange` vs `linspace`

|    | `arange` | `linspace` |
|:---|:---|:---|
| шаг | фиксированный | фиксированное **число** точек |
| `stop` | не входит | **входит** последняя точка |

```python
np.arange(10)          # [0, 1, 2, ..., 9]
np.arange(3, 10, 3)    # [3, 6, 9]
```

## 🔷 `np.zeros` и `np.ones` — шаблоны

Массив заданной формы, заполненный нулями / единицами:

```python
np.zeros(форма)              →  везде 0.0
np.zeros((строки, столбцы))  →  таблица из нулей
np.ones(форма)               →  везде 1.0
np.ones((строки, столбцы))   →  таблица из единиц
```

| вызов | результат |
|:---|:---|
| `np.zeros(5)` | `[0., 0., 0., 0., 0.]` |
| `np.zeros((3, 2))` | матрица 3×2 из нулей |
| `np.zeros(3, dtype=int)` | `[0, 0, 0]` |
| `np.ones(5)` | `[1., 1., 1., 1., 1.]` |
| `np.ones((3, 2))` | матрица 3×2 из единиц |

| функция | чем заполняет |
|:---|:---|
| `np.ones` | **1** |
| `np.zeros` | **0** |

> ⚠️ 2D — только **кортеж**: `np.zeros((9000, 10))`, а **не** `np.zeros(9000, 10)` (ошибка).

> 💡 `np.zeros_like(a)` / `np.ones_like(a)` — нули / единицы **той же формы** (и `dtype`), что `a`.

```python
a = np.zeros(4, dtype=int)   # [0, 0, 0, 0]
a[0] = 7
a[1] = 2
# [7, 2, 0, 0]

np.ones((3, 1))
# [[1.]
#  [1.]
#  [1.]]
```

> 💡 Склеить столбец единиц с матрицей (bias для линейной модели):
> `np.hstack([A, np.ones((A.shape[0], 1))])`.

## 🔷 `dtype` — тип элементов

В NumPy у массива **один** тип на весь массив (не как у `list` в Python).

```python
a = np.array([1, 2, 3]);   a.dtype   →  int64 (или int32)   # целые
b = np.array([1.0, 2.5]);  b.dtype   →  float64             # дробные
```

Смотреть тип: `a.dtype`. Задать при создании: `np.array(..., dtype=...)`, `np.zeros(..., dtype=...)`.

| dtype | смысл |
|:---|:---|
| `int`, `int32`, `int64` | целые |
| `float`, `float32`, `float64` | дробные |
| `bool` | True / False |
| `str` / `U...` | строки |

По умолчанию чаще всего: целые → `int64` (или `int32` на системе), дробные → `float64`.

### Смешанные типы → повышение

Если в списке и целые, и дробное — **весь** массив станет дробным:

```python
np.array([1, 2, 3, 1.5])
# array([1. , 2. , 3. , 1.5])   dtype=float64
```

Почему: нужен **один** тип, в котором можно хранить всё без потерь. Порядок «силы» (упрощённо): `bool` < `int` < `float` < `str`. Ошибки нет — NumPy сам **повышает** тип (upcasting).

## 🔷 `astype` — сменить тип

```python
a.astype(новый_тип)   →  новый массив, числа приведены к типу
```

Исходный массив **не меняется** — возвращается **копия**.

```python
a = np.array([1.7, 2.3, 3.9])
a.dtype              →  float64

b = a.astype(int)
b                    →  array([1, 2, 3])   # дробная часть отброшена
b.dtype              →  int64

a                    →  всё ещё [1.7, 2.3, 3.9]   # оригинал цел
```

| вызов | смысл |
|:---|:---|
| `a.astype(float)` | целые → дробные (`3` → `3.0`) |
| `a.astype(int)` | дробные → целые (**обрезание**, не округление!) |
| `a.astype(bool)` | 0 → False, остальное → True |
| `a.astype(np.float32)` | меньшая точность / меньше памяти |

| способ | когда |
|:---|:---|
| `np.array([1, 2], dtype=float)` | сразу создать нужного типа |
| `np.zeros(5, dtype=int)` | нули сразу целые |
| `a.astype(float)` | уже есть массив — сменить тип |

> ⚠️ Частые ошибки: ждать округления от `astype(int)` (`1.9 → 1`, не `2`); ждать, что `astype` изменит `a`; думать, что в массиве могут жить разные типы.

## ✅ Коротко запомнить

| # | Правило |
|:---|:---|
| 1 | `np.array([...])` — из готовых данных; вложенные списки → 2D+ |
| 2 | `arange(stop)` → `0..stop-1`; **`stop` не входит** (как в срезах) |
| 3 | `arange` — фиксированный **шаг**; `linspace` — фиксированное **число точек** |
| 4 | 2D-шаблон — только кортеж: `zeros((N, K))`, `ones((N, K))` |
| 5 | `zeros_like(a)` / `ones_like(a)` — форма и `dtype` как у `a` |
| 6 | `dtype` — один тип на весь массив; `int` + `float` → весь `float` |
| 7 | `astype` — **копия** с новым типом, оригинал не трогает |
| 8 | `astype(int)` **обрезает** дробную часть, не округляет |
